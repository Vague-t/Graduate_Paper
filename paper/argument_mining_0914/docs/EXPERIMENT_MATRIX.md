以下为新实验计划，所有真实数据行状态均为 **NOT_RUN**。固定数据 ID、坐标转换和评价脚本后再训练，不按旧分数调参。

|研究问题|训练条件|推理配置/控制|最低交付证据|
|---|---|---|---|
|Single-Pass 到 Full 的整体差异|baseline 与 full 分别训练|baseline_single 与 full_br_k3|每个 run 的独立身份，不再混用 81.67/77.82|
|配套训练模块是否有效|固定增强数据；移除 claim/cue/aux 分别重训|固定 full_single 或 staged_k1；不能复用 Full 适配器假装消融|分类别 P/R/F1、参数数目、实际更新步数|

|合法优先的作用|同一检查点/池|valid_first 单独变体|不能沿用默认流程旧分数|
|CDCP 域内|CDCP train/dev 单独训练|cdcp_full_br_k3|多前提处理与图约束兼容性审查|
|零样本迁移|仅 AAEC train/dev|aaec_to_cdcp；评价显式 --coarse|目标数据使用记录、源标签输出与确定映射|

推荐顺序：小规模格式/显存试跑 → 单候选与 Full 基础实验 → 同池推理消融 → 增强与参数预算对照 → 多种子 → 迁移与效率评估。验证器布尔输出失败率高时，先在 dev 上修订提示或验证器，再冻结配置；不允许在 test 上逐条修提示。

“同检查点”用于推理消融；“重新训练”用于训练模块/数据消融，不能互换。训练模块配置必须与保存的适配器一致。同候选池对照应从一次完整候选生成运行导出缓存，而不是仅把 seed 写成一样就认定候选相同。

统计至少报告各次实际运行分数、均值、样本标准差及失败文档数；建议 5 个预先固定种子，而非从尝试中挑选最佳 5 个。显著性、置信区间及多重比较校正需要另定统计方案，本项目未自动完成。单个测试集合上的多种子运行不等于多个独立数据集。

还需补做但本项目未包含的基线：实际语法约束解码、DAG 后处理、Self-Refine、外部模型/近期方法同协议复现、Llama 验证器。预算比较须同时包含生成和验证，统计完整端到端时延、P95、峰值显存、输入及输出 token；缓存命中后的墙钟时间不能混入未缓存基线比较。

每次真实实验先登记：研究问题、配置 SHA256、代码 SHA256、数据文件及划分 SHA256、种子、骨干/适配器身份、硬件/驱动、预算、检查点选择、失败策略、统计口径。不要手工把新的结果贴到旧表对应行；先建立新的独立结果表，确认协议后再决定替换旧记录。
