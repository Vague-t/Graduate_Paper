# 第一章 绪论

## 1.1 研究背景与问题提出

论辩挖掘将观点、理由及连接方式转化为结构化对象[1]。严格抽取不仅要求关系含义正确，还要求组件文字范围、角色与方向均正确。一个端点的边界变化会改变所有引用它的关系身份。

以AAEC训练文档essay001为例，Premise T4的原文为“What we acquired from team work is not only how to achieve the same goal with others but more importantly, how to get along with others”，标注为支持Claim T3：“through cooperation, children can learn about interpersonal skills which are significant in the future life of all students”。同文档中的T5、T6也分别支持T3，三个理由不是可以随意互换的显示编号。

图1-1 AAEC essay001的原生关系子图；中文仅为阅读提示，评价使用附录I的英文原文和字符跨度。

训练增强若改变T3或其理由的含义，关系监督就可能失效；推理若把T4抽成较短片段，原来的T4→T3不能仅凭编号沿用。本文分别研究改写后的可靠监督与组件修改后的完整依赖决策，并通过相同数据、相同候选评分的比较控制其他变化。

复杂机制的价值由比较结果决定。第三章报告数据构造与学习目标的分项，第四章比较纯关系修正、单对象共同决策、集合动作与重生成，第五章检查两阶段作用是否重叠。真实CPU案例既保留误边减少，也保留误删，以避免从单个成功文档推断总体效果。

## 1.2 国内外研究现状

相关研究从组件识别逐步扩展到联合结构预测，并形成生成建模、数据增强和预测后修正等路线。本文按这些机制组织综述，重点关注输入是否包含金标组件、关系依赖如何进入模型，以及修改后如何判定结构质量。AAEC和CDCP的任务表示及评价规则统一在第二章说明。

### 1.2.1 端到端论辩挖掘与生成建模

组件与关系的联合预测是端到端论辩挖掘的基础。Stab和Gurevych围绕说服性作文建立组件与关系分析方法[2]；Eger等将组件识别与论证结构预测纳入神经端到端学习框架[4]；Morio等通过双仿射解析和任务特定参数化支持非树状结构预测[5]。这些工作使组件识别、关系判断和结构约束能够在统一任务中研究，同时提示不同语料不能一律按树结构处理。

生成式方法进一步统一了多个子任务的输出接口。Kawarada等将论辩挖掘表述为文本到文本生成，为本文的直接生成式对照候选[7]。Cabessa等把组件分类、关系识别和关系分类组织为生成任务，其方法基于已有组件列表展开，评价范围与从原始文本定位跨度的设定不同[8]。AASP则以受约束的预定义动作逐步构建论辩结构，将结构信息引入自回归生成过程[9]。本文依据该工作的2025年公开预印本讨论其机制。

GMAM通过约束指针与重构位置编码生成组件和关系序列[47]，提供了处理输出依赖的一种紧凑方式。UniASA则将多种论辩结构任务统一为序列生成，并引入子任务分解的多视图学习[48]。前者适合参照结构生成机制，后者适合考察统一表示与辅助任务的作用；本文的成对学习另以同一原文及其经过检查的改写为对应单位。统一生成、辅助目标与对应约束解决的问题有所联系，其比较需要固定输入及完整对象评价，而不能仅按是否使用大模型分类。

结构与语义信号为生成提供了更具体的条件。DENIM使用篇章结构感知前缀辅助端到端预测[12]；Das等以关联组件间的关键短语表达概念联系[13]；FOL-AM利用一阶逻辑规则组织关系查询和多跳推理[14]。后两项工作以已分割组件为前提，适合用于比较关系语义建模思想，不能直接把分类分数视为严格整图抽取成绩。

组件边界仍是生成系统中的重要误差来源。Caputo等在2026年采用成对标签进行细粒度组件分割，并分析自动分割对后续分类的影响[6]。同年的ARGUS系统整合组件分割、组件分类、关系识别与分类，并连接符号求解器开展论辩框架分析[10]。结合LLM论辩挖掘综述所讨论的任务和评价差异[11]，本文将研究重点落在可独立检验的监督保持与结构恢复机制，而非模型规模或生成式接口本身。

### 1.2.2 关系保持数据增强

数据增强通过改变表达扩充监督，但生成内容与原标签之间的对应需要单独检查[15]。CoDa从训练实例提取生成约束[16]，SegMix在任务相关片段上进行结构感知混合[17]。这些方法表明，增强的作用不仅取决于样本数量，也取决于生成条件和标签可靠性。

论辩挖掘中的直接近邻是质量导向合成QOS。该方法将上下文和组件组织为槽位化输入，在改写后恢复跨度并继承组件类型及关系标注；其方法节说明，论辩关系并未显式提供给生成模型，而依赖语义保持使原关系继续成立[35]。本文沿用槽位化改写与标注恢复这一研究基础，进一步关注改写的关系影响范围：同时考察集合内部、跨边界的合法端点组合，以及已有关系和无关系状态。

QOS与同文提出的多样性导向合成DOS分别提供质量和多样性的参照[35]；本文的QOS式适配只继承其中的槽位化改写思想，不能代表两种方案或原论文完整系统的复现。2026年10月公开的对抗强化学习合成研究交替优化生成器与判别器，生成新的文本—结构标注对[49]。结构质量与多样性的联合考虑已有直接近邻，不能作为本文排他的研究空白。本文限定为保留原图监督的局部改写，其增量分别由关系影响域检查和对应因素学习的对照检验。两类数据构造目标不同，比较时先统一训练规模和下游抽取器，再解释结构新颖性与表达变化。

关系抽取研究为这种质量控制提供了相邻思路。ConsistRE以关系条件和上下文约束组织细粒度生成[38]，CovEReD通过反事实实体替换研究文档级关系预测的一致性[37]，ODDA关注低资源条件下增强样本的质量与多样性[39]。Wang等将LLM生成样本用于联合实体关系抽取，结合一致性正则化、伪标签与迭代反馈[36]。对后一工作的认识限于出版方摘要和方法摘录，未核实的细节不用于排除性比较。

增强还可能改变模型对表面线索的依赖。话语标记补全的效果因语料而异[40]，弱监督论辩挖掘也需要处理组件边界和关系噪声[18]。因此，本文同时评价标签漂移、表达多样性、接受覆盖和训练成本，并在同一批增强样本上比较不同学习目标，以区分数据构造与成对监督的作用。“保持”是生成和审核目标，其语义可靠性仍需真实审计与任务评价支持。

### 1.2.3 结构化预测与论辩图修正

结构化预测可以在生成时施加约束，也可以在生成后选择和修正候选。语法约束解码通过限制后继token控制输出形式[19]，AASP则把结构动作约束纳入生成过程[9]。这类约束保证的是已编码的规则，跨度是否准确、关系是否成立还需要依据文本与标注评价。

生成后修订和多候选聚合提供了另一类接口。Self-Refine利用反馈迭代修订输出[20]，自一致性通过采样多条路径聚合答案[22]。在缺乏外部反馈的推理设置中，自纠错也可能无效或降低表现[21]。论辩分析中的LLM-refine生成不同Claim、Evidence和Warrant组合，再选择分割结果[23]。上述研究支持对候选与判断过程分别分析，而不是默认更多修订必然带来收益。

对象与关系的联合处理也存在直接近邻。Re-Cent以关系标签引导跨度对抽取，并通过关系与跨度对之间的相关性实施修正[43]。Pirozelli等的论辩重构流程提供组件合并、重写和关系检查步骤，其允许改写组件表述，区别于原文字面跨度抽取[44]。Xiao和Li的ARGUS研究则把LLM自解释转为抽象论辩框架，以形式语义定义最小代价修复目标[24]；它与前述同名论辩挖掘系统不是同一工作，修复目标也不同于本文的抽取对象效用。

本文的直接基础是ICIC 2026提出的多候选重排序与有界修正方法MCR-BR[34]。原方法已包含候选跨度替换、类型调整和关系修改。本文进一步把兼容组件集合替换及全部受影响关系的重建作为完整事务，显式规定评分、约束、预算和回退，重点研究修改之间的依赖如何进入决策。

评价目标为上述设计划定了边界。F1的最优决策一般不能由单个对象的边际概率直接替代[41]，校准概率与最优F1阈值的关系也依赖特定条件[42]。概率校准用于检查置信度与经验正确率的对应[45]。本文据此区分对象概率、代价敏感效用和严格抽取F1，以同候选、同评分的比较检验事务机制，并独立报告错误接受与计算成本。

### 1.2.4 综合评述与本文研究位置

不同语料的任务表示和训练来源会影响方法比较。MT-AM利用辅助论辩语料开展多任务训练[25]；AMELIA统一19个数据集的格式，并比较单任务、多任务及模型合并策略[26]。句子级泛化研究还观察到模型对数据集相关词汇线索的依赖[27]。本文以两种原生任务检验方法的适用范围，并将附录中的历史跨域结果单独保留。多任务训练、单源零样本迁移和目标域校准具有不同数据条件，不合并为一种“泛化”成绩。

### 1.3.1 研究问题

RQ1：在局部改写后，怎样识别可用于学习的组件与关系对应？在相同来源、变体规模和更新预算下，因素级辅助监督与成对学习分别提供多大增量？完整筛选是否值得其额外拒绝和审核成本，由单独对照回答。

RQ2：在候选和评分充分时，怎样完整处理组件修改的关系依赖，并控制误改与计算成本？单对象、集合动作以及局部、全局求解分别在什么规模和预算下适用？有限候选之外的遗漏不归因于搜索器。

两阶段四格比较用于识别相对ICIC继承配置的条件增量；对象成员分析用于解释重叠、独有恢复和新增损失。它们不另列为第三项算法创新。

### 1.3.2 主要研究内容

（1）可靠对应因素上的关系感知成对学习。保留关系影响域和完整标注输运，通过逐因素状态区分通过、变化、原标签分歧和未审核。原文承担完整图生成监督；变体只在有效组件及可靠关系上提供辅助监督与分布对齐，避免将未知监督当作已经保持。完整影响域整例筛选作为可选数据策略，与默认因素掩码分别比较。

（2）候选质量与评分约束下的依赖闭合修正。将成分提案、原生类型及源组表示作为输入条件，把组件变化及全部受影响关系重建组织为统一事务。通过缺失分数保护、开发侧风险选择及全局或局部求解，分别控制不可评价的修改、误改代价与计算开销。依赖闭合是共同语义；集合动作和局部搜索是可替换实现。

候选接口与评分训练用于落实这两项研究，不额外包装为独立创新。训练辅助头与推理评分器的监督对象和使用阶段保持区分。

## 1.4 论文组织结构

第二章统一任务、数据、配置及统计协议；第三章定义可靠对应与成对学习并报告训练和审核；第四章定义依赖闭合修正并报告评分、覆盖、比较、资源及真实案例；第五章以四格和对象成员分析两阶段关系；第六章总结收益和适用条件。附录提供数据坐标、实现验收、登记、外部对照、逐种子记录与案例定位。
