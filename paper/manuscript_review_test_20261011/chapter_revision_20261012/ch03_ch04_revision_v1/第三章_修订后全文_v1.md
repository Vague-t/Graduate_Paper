# 第三章 关系影响域约束的增强与成对学习

## 3.1 引言

在端到端论辩挖掘中，组件文字既承载自身的论辩角色，也为与其他组件之间的关系提供依据。因此，局部改写即使保持句意相近，也可能改变支持方向、削弱跨边界理由，或使原本没有标注关系的因素获得新的解释。若直接将全部旧标签复制到增强文本，增加的样本可能同时引入错误监督。

本章研究在组件位置变化和关系语义不确定的条件下，如何构造可追踪的增强视图，并将其中通过检查的监督用于训练。方法首先定义改写的关系影响域，在字符坐标上迁移全部组件；随后分别审核组件与关系，对变化、待定及未审核的因素设置掩码；最后在固定视图和掩码上比较无成对、组件成对与完整成对学习。

本章依次介绍总体框架、增强构造、学习目标及算法性质，再通过受控比较讨论整套训练配置、成对目标和审核成本。需要区分两项判断：可靠因素接口明确了哪些标签参与学习；成对项是否带来独立收益，仍须由固定数据条件下的比较回答。

本章沿用test稿件的模拟评审用途。主结果、审核统计与成本数值为原稿的模拟材料；新增的完整增强示例为明确标注的教学构造，均不能代替目标模型的真实运行证据。表3-1单独保留真实语料的原文与标注身份。

## 3.2 总体框架与基础模型

整体框架包括增强构造与参数学习两部分。构造阶段读取训练文档和原生标注，输出新全文、全部组件的对应φ以及可靠因素掩码；学习阶段保留原文完整生成监督，并在增强侧只学习通过检查的因素。图3-2展示二者进入共享生成器后的连接。类型条件LoRA、线索提示和句子监督构成继承基础，本章新增部分是关系影响域约束、可靠监督接口及受控的成对学习目标。

### 3.2.1 类型条件低秩适配

本节说明继承的专项建模与新增学习目标的接口。参考骨干为 Qwen2.5-7B-Instruct，冻结基础权重，在注意力投影中保留全局和结论专项低秩分支；LoRA 参数化沿用已有方法[32]。对于 ${W}_{0}∈{R}^{{d}_{out}×{d}_{in}}$，定义

$h{′}_{t}={W}_{0}{h}_{t}+\frac{α}{r}{B}_{g}{A}_{g}{h}_{t}+{g}_{t}\frac{α}{r}{B}_{c}{A}_{c}{h}_{t},  {A}_{⋅}∈{R}^{r×{d}_{in}}, {B}_{⋅}∈{R}^{{d}_{out}×r}.$

全局分支参与所有位置的计算，结论分支由 ${g}_{t}∈{0,1}$ 控制。字段按 id、type、span 排列；可见前缀中的结论类型值完整闭合后，门控在该组件的后续字段开启，并在组件结束时关闭。AAEC 和 CDCP 的触发类型分别为 Claim/MajorClaim 和 Policy/Value；输入、未闭合类型字段及关系区域均令 ${g}_{t}=0$。教师强制训练也仅使用可见前缀。

这一门控作用于类型确定后的跨度等字段，不回溯修改已输出类型。参考配置取 $r=16$、$α=32$，以单一全局 rank-32 分支作为参数量匹配对照；实际计算成本另行测量。

### 3.2.2 线索提示与原有监督

连续提示沿用参数高效提示调优机制[33]。对 therefore、thus、in conclusion、consequently、hence、to conclude 作不区分大小写的词边界匹配；命中时在聊天模板输入嵌入之前插入四个向量 ${P}_{i}∈{R}^{d}$，未命中则不插入。提示位置不计入原文坐标。

词典只控制提示启用，不赋予结论标签。话语标记的收益不能由标记数量直接推定[40]；原文与增强文分别按各自文本触发提示；该规则沿用MCR-BR配置，本章不将其单独计为新增机制。

生成目标对有效回答 token（含 EOS）取平均，聊天输入和提示向量不参与该项损失：

${L}_{gen}\left(x,G\right)=-\frac{1}{{T}_{y}}\sum_{t=1}^{{T}_{y}} log{p}_{θ}\left({y}_{t}∣x,{y}_{<t}\right).$

句子辅助任务沿用 ICIC 专项监督思路：按句末标点和文档结尾分句，对输入最后一层隐藏状态作句内均值池化，经线性层和 sigmoid 得到 ${\hat{z}}_{i}$。句子与结论类金标跨度相交时令 ${z}_{i}=1$，否则为零；跨句组件可标记多个句子。定义

${L}_{sent}=-\frac{1}{{N}_{s}}\sum_{i=1}^{{N}_{s}} \left[{z}_{i}log{\hat{z}}_{i}+\left(1-{z}_{i}\right)log\left(1-{\hat{z}}_{i}\right)\right],  {L}_{ICIC}={L}_{gen}+{λ}_{sent}{L}_{sent}.$

参考配置取 ${λ}_{sent}=0.5$。句子头只读取输入表示，用于共享表示学习。上述生成目标与句子监督构成继承目标 ${L}_{ICIC}$；3.3节构造增强视图，3.4节在此基础上引入组件、关系头及成对监督。

## 3.3 关系影响域与可靠增强视图

### 3.3.1 改写范围与关系因素

本章的文本改写是训练数据增强：只替换已标注组件所对应的文字，不重写整篇文章，也不重新决定组件类型或关系答案。改写集合由组件组成，不必对应一个连续段落。“内部”与“跨边界”均相对于这个集合定义，与是否跨句、跨段没有直接等价关系。

“内部／跨边界”描述端点与改写集合的位置关系，“正关系／NONE／语义未知”描述因素状态，二者分别记录。默认路径保留有效组件，屏蔽关系层面的不确定监督；完整筛选路径才因任一可审核因素失败拒绝整例。已知联合源真子集的语义未知状态按3.3.3节处理，不伪装成已经确认的NONE。

对训练金标图 $G=\left(C,R\right)$，每篇文档固定一个中心。AAEC优先集合为Claim与MajorClaim，CDCP为Policy与Value；后者只定义本方法的触发角色，不改写原生类型。对固定种子17、语料、文档ID、组件ID及center标记按竖线连接，计算SHA-256，按前16位哈希数值选取第一个对象。中心使用固定种子17，同一文档全部视图复用同一中心；不依据生成成功率换中心。

优先集合为空时，从全部合法金标组件按同一顺序回退，并记录fallback；组件集合为空时保留原文、跳过增强。改写集合$A$由中心及所有指向中心的金标关系的完整源成员组成，去重、不递归扩展。无入关系时仅改写中心；超过三源成员的金标超边仍完整纳入，新增NONE因素的元数预算不截断金标。其余组件文字只读。

若槽位重叠或完整输入超过冻结上下文上限，则跳过该文档增强并记录原因，不删除源成员或改选中心。默认因素掩码版本仅审核声明的有限子集；完整筛选版本在完整影响域无法处理时跳过，二者分别登记审核覆盖。不同模型的上下文及调用上限由运行清单提供；未提供时不启动生成。每文档最多四次尝试、两个接受变体，原始样本始终保留。该选择控制定义和资源，不意味着结论中心已经优于其他中心。

记 $Ω\left(C\right)$ 为协议允许的完整端点组合集合，因素 $ω=\left(S,v\right)$ 由非空源组件集合 $S$ 和目标 $v$ 构成。AAEC 中 $\left|S\right|=1$，枚举全部合法有向组件对；内部正边、边界正边和其余合法对均纳入候选。因素标签 ${y}_{ω}$ 为协议规定的关系状态。在可审核因素宇宙内，无标注关系记作NONE；已标注联合源真子集的语义未知例外按3.3.3节定义，先从语义监督和审核域中排除。若协议允许同一端点组合具有多个标签，则使用合法标签组合表示状态，不能通过任取一个标签丢失监督。

CDCP 保留 $\left({{c}_{{i}_{1}},…,{c}_{{i}_{k}}},{c}_{j},ℓ\right)$ 的原生多前提超边，$ℓ∈{Reason,Evidence}$。源成员按原文顺序规范化，整条超边作为一个关系对象，不展开为独立二元关系。

训练因素宇宙包含全部金标超边的端点组合，并补充满足源范围规则、最多含三个源成员的候选组合。超过三个源成员的金标关系仍全部保留。源范围的连续性依据所选组件序列判定，而非要求原文字符之间没有间隙。

NONE 仅在上述有限宇宙内定义，不涉及组件集合的全部子集。三源成员预算使更长的金标超边缺少同元数NONE对照，可能形成长度相关的监督偏置，需按元数诊断。这一辅助头不用于估计长超边的完整对象正确率。

设 $V\left(ω\right)=S∪{v}$，完整影响域定义为

${D}_{A}={ω∈{Ω}_{sem}\left(C\right):V\left(ω\right)∩A≠⌀}.$

其中 ${Ω}_{sem}\left(C\right)=Ω\left(C\right)∖{U}_{sem}$，未知集合见3.3.3节；AAEC没有这一联合源子集例外。二元情形即 ${\left(u,v\right):u∈A∨v∈A,\left(u,v\right)∈{Ω}_{sem}\left(C\right)}$。全部端点位于 $A$ 中的因素属于内部因素，仅部分端点位于 $A$ 中的属于边界因素。这里的“完整”限定于预先声明的因素宇宙；NONE也是标注协议中的无边状态，不代表任意语义解释下均无联系。改写可能经指代或篇章语境影响两个只读端点，这类域外漂移纳入人工审计。资源裁剪版本另报因素覆盖率，并标记为近似设置。

### 3.3.2 条件生成与字符坐标迁移

增强模型接收全文、可改写组件的槽位和类型、只读端点目录及影响域标签。条件可采用“全部合法端点目录、显式正关系表、语义未知例外清单、其余可审核因素为NONE”的无损编码，避免逐条重复大量无边因素；验证和训练时仍按展开后的因素执行。输出限定为组件 ID 到替换文本的映射，不允许新增组件、修改类型或自行重建关系表。

程序按原始字符区间执行槽位替换，随后对完整文档重新分词，建立组件对应

$\phi:C\to C^{\prime},\quad(d,b_c,e_c,t_c)\mapsto(d^{\prime},b_c^{\prime},e_c^{\prime},t_c).$

组件采用第二章定义的规范身份：文档版本、原文字符半开区间和原生类型。增强全文是另一个文本版本，故记为d′；显示ID仅建立追踪对应，不能替代坐标或版本身份。回填后更新所有组件的字符区间，再派生评价token与模型子词表示；只读组件也会随前文长度变化而移动。φ是组件之间的双射，不是字符或token位置之间的双射。关系及超边的全部端点经过同一φ迁移。槽位重叠、坐标往返不一致或端点无法无损输运时，拒绝该视图并保留原始样本。

表3-1提供了迁移前的真实原生对象；3.3.4节另用一个可逐项计算的教学文档展示回填、φ、审核结果及监督掩码。二者的证据身份分别保留，不将教学改写称为模型实际输出。

### 3.3.3 审核掩码与语义未知因素

所有版本先检查格式、槽位身份、坐标往返和完整端点引用，再在全文上下文中检查改写组件的含义、角色、指代、否定与模态。格式失效或确认改变组件含义时拒绝整个变体；组件意义待定时也不接纳该变体。原始文档和金标不因模型判断而删除。

通过组件检查后，默认采用因素掩码。关系审核子集 ${J}_{A}⊆{D}_{A}$ 包含全部受影响正关系，并按固定哈希最多抽取内部、跨边界NONE各4项；已知CDCP联合源的单成员不机械记作负例。正关系无法在资源内全部核查时，本次变体不进入关系学习，但通过检查的组件仍可提供组件级监督。未审核的NONE不被当作已经稳定。

验证器分别判断原文因素和改写因素。仅当原标注获认可、改写后状态仍一致、完整端点对应有效时，令 ${m}_{R}\left(ω\right)=1$；原标签分歧、变化或待定均令其为0。组件同样保存 ${m}_{C}\left(c\right)$，用于头监督和对齐的只读端点也在全文上下文中审核，不能只因字面未变就判定其论辩角色稳定；关系掩码为1还要求全部端点的组件掩码为1。判定来自固定模型，故“可靠”表示通过声明的检查，不是人工金标准语义保证。

默认策略不因某个关系未通过而丢掉所有有效组件，也不把该关系改为NONE。变体保存完整输运图以供追踪，但只有掩码为1的标签参与增强侧损失。完整筛选对照则检查声明影响域的全部因素，任一变化或待定即拒绝整例，其余生成和训练资源按共同规则登记。若完整筛选损失源覆盖却未改善学习，采用因素掩码即可。

每篇最多四次尝试、最多两个接受视图；记录模型、提示、原始判断、掩码、对应、拒绝原因及全部成本。原文和变体按源文档共同分组。因素掩码是本章声明的默认设计，其漂移和覆盖由3.6.3节独立诊断；不能依据测试结果反向选择掩码策略。

验证时先不给出待判断因素的正确答案，取得分类后再与原标签比较；审核者按固定规范独立作答，再由裁决者形成参照。独立上下文或参数分离都不能保证审核误差独立。

严格抽取评价只问一个完整对象是否在金标中。若金标为 $h=\left({{c}_{1},{c}_{2}},{c}_{3},Reason\right)$，预测 $\left({{c}_{1}},{c}_{3},Reason\right)$ 就是不同对象，不能匹配该金标。但是完整联合理由成立，不推出单一成员在语义上既不支持也不反对目标。

为此，训练语义头另定义未知集合 ${U}_{sem}$：对已标注联合源，若同目标的非空真子集没有任何单独正关系标注，则将该端点因素列为语义未知。显式正标注优先，不屏蔽已有单源正关系。${Ω}_{sem}=Ω∖{U}_{sem}$ 为可审核因素宇宙，完整影响域与抽样集合均在该宇宙内定义。完整筛选的“全部”指这里已声明的可审核域，未知项另计数量，不称为已经通过。

原文和变体的语义关系头均不把 ${U}_{sem}$ 当作NONE负例；相应监督与对齐掩码都为0。原文完整生成目标仍保留原始超边，金标不删不改。第四章评分器预测的是“完整对象是否与标注精确匹配”，因此该真子集可作为完整对象不匹配的负例，其0标签不解释为语义上没有关系。推理NONE继续表示该槽位未选正关系。由此分开标注存在性、语义审核与推理决策三种用途。

将通过审核且端点组件也通过检查的关系集合记为$R_A$，则各层满足

$R_A ⊆ J_A ⊆ D_A ⊆ Ω_{sem},\quad Ω_{sem}=Ω∖U_{sem}.$

完整影响域$D_A$是定义范围，$J_A$是实际审核范围，$R_A$才是增强关系损失的入口。默认$J_A$通常小于$D_A$；完整筛选才令$J_A=D_A$，语义未知$U_{sem}$始终在两者之外。图3-1的两个分支应按这一集合关系理解。

|b→d NONE|原新标签一致|mR=1|NONE监督与成对项|
|域外c→d NONE|不在影响域|mR=0|保留原文监督 不进入增强侧关系损失|

该视图通过组件门，虽有一项关系待定，仍由默认因素掩码策略接纳。设这篇源文档仅有一个接受视图，则md=1，头监督为(S原文+Sm增强)/2。组件对齐集合A+={a,b,c}，每项先取1/3；d只参与可靠NONE端点，不因此进入组件对齐。关系对齐的正关系组和NONE组各有一项，组权重各为1/2；乘默认λR=0.5后，两项各占0.25。原文完整生成及句子监督的权重不变，增强输运图不作为完整生成答案。

再考虑第二次构造尝试，将a改为“Teamwork does not help children learn social skills.”。新增否定改变原组件含义，整视图在组件门被拒绝，不进入Views，不增加md，也不参与任何增强损失；原文监督及第一条已接受视图保留。如果随后另有一个真实接受视图，md才增至2，头监督的每视图权重变为1/3，成对项再按两个接受视图平均。

该示例使坐标、掩码与权重可被复算，却不验证模型生成或语义审核的实际可靠性。真实机制验证仍需提供相同字段的目标流程原始输出，尤其是“部分掩码接纳”与“语义变化拒绝”各一条。

### 3.4.1 辅助预测与可靠因素对齐

组件类型头和关系状态头以共享生成器的输入表示为基础，使用金标跨度定位训练因素。下游生成器只接收任务指令及原文或增强文；增强构造阶段使用的金标槽位、类型与关系条件仅用于监督，不进入该模型的输入。

令 ${h}_{i}^{x}$ 为输入子词隐藏状态，${B}_{x}\left(c\right)$ 为组件字符跨度对应的输入子词集合，${h}_{end}^{x}$ 为全文输入结束且回答尚未开始处的隐藏状态。坐标映射和输入隔离的实现验收要求见附录F.2。组件表示与类型分布定义为

${u}_{c}^{x}={MeanPool}_{i∈{B}_{x}\left(c\right)}{h}_{i}^{x},  {p}_{C}^{x}\left(c\right)=softmax{f}_{C}\left(\left[{u}_{c}^{x};{h}_{end}^{x}\right]\right).$

因果模型的早期 token 只能访问左侧上下文。拼接 ${h}_{end}^{x}$ 为跨度表示补充全文上下文通道，并不改变模型的因果注意力结构；组件头不输入待预测的金标类型。

关系头显式区分源和目标，写为

${p}_{R}^{x}\left(S,v\right)=softmax{f}_{R}\left(\left[Pool\left({{u}_{c}^{x}:c∈S}\right);{u}_{v}^{x};{h}_{end}^{x};η\left(S,v\right)\right]\right),$

其中fC、fR为两层感知机，Pool为源成员表示的算术均值。η包含源成员数、源起点的最小值和均值、源终点的最大值和均值，以及目标起止位置；这里的位置是由规范字符区间派生的评价token坐标，并除以文档token数。它们仅为输入特征，不参与规范对象去重，亦不替代字符残差。η不包含待预测的关系标签；二元关系使用单一源表示，超边以完整源集合和目标作为监督对象，状态包含NONE。两个辅助头在开发评价和测试时移除。

组件对齐应覆盖被改写的组件及其正关系所连接的只读端点，定义

${A}^{+}=A∪⋃_{\begin{matrix}ω∈{D}_{A} \\ {y}_{ω}≠NONE\end{matrix}}V\left(ω\right).$

即改写组件以及通过正边或超边相连的只读端点。NONE 因素进入关系项，但不因此把全部远处组件都纳入组件对齐。对通过组件检查的视图 $x′$，以下公式中的 ${A}^{+}$ 进一步与 ${c:{m}_{C}\left(c\right)=1}$ 取交集，组件对齐为

${L}_{C}^{align}\left(x,x′\right)=\frac{1}{\left|{A}^{+}\right|}\sum_{c∈{A}^{+}}^{​} JS\left({p}_{C}^{x}\left(c\right),{p}_{C}^{x′}\left(ϕ\left(c\right)\right)\right),$

其中 $JS\left(p,q\right)=\frac{1}{2}KL\left(p∥\hat{p}\right)+\frac{1}{2}KL\left(q∥\hat{p}\right)$，$\hat{p}=\left(p+q\right)/2$。不对任一视图停止梯度。

将通过检查的集合 ${ω∈{J}_{A}:{m}_{R}\left(ω\right)=1}$ 划分为正关系组 ${D}_{+}$ 和 NONE 组 ${D}_{0}$，令 $B={b∈{+,0}:\left|{D}_{b}\right|>0}$。关系对齐采用组间、组内两级平均：

${L}_{R}^{align}\left(x,x′\right)=\frac{1}{\left|B\right|}\sum_{b∈B}^{​} \frac{1}{\left|{D}_{b}\right|}\sum_{ω∈{D}_{b}}^{​} JS\left({p}_{R}^{x}\left(ω\right),{p}_{R}^{x′}\left(ϕ\left(ω\right)\right)\right).$

这样可避免数量较多的 NONE 因素仅凭数量淹没正关系。当可靠关系集合为空时，该项置零，不人为添加关系；原文全部关系的生成监督仍保留。${A}^{+}$ 为空时组件对齐也置零。

低JS可能来自两个视图一起预测错误，故同时保留标签锚定。对视图 $x$、受监督组件集合 ${M}_{C}$ 和受监督关系因素集合 ${M}_{R}$，令 ${M}_{R}^{+}$、${M}_{R}^{0}$ 分别为其中的正关系与NONE因素，${B}_{M}={b∈{+,0}:\left|{M}_{R}^{b}\right|>0}$。辅助监督完整定义为

$S\left(x;{M}_{C},{M}_{R}\right)=\frac{1}{\left|{M}_{C}\right|}\sum_{c∈{M}_{C}}^{​} CE\left({p}_{C}^{x}\left(c\right),{t}_{c}\right)+\frac{1}{\left|{B}_{M}\right|}\sum_{b∈{B}_{M}}^{​} \frac{1}{\left|{M}_{R}^{b}\right|}\sum_{ω∈{M}_{R}^{b}}^{​} CE\left({p}_{R}^{x}\left(ω\right),{y}_{ω}\right),$

其中 $CE$ 为交叉熵，${t}_{c}$ 为组件原生类型；组件项在 ${M}_{C}=⌀$ 时取0，关系项在 ${B}_{M}=⌀$ 时取0，两项等权相加。原文取 $S\left(x,G\right)=S\left(x;C,{Ω}_{sem}\left(C\right)\right)$，即全部原生组件及可审核因素，语义未知集合不参与关系头监督；变体取 ${S}_{m}\left(x′,ϕ\left(G\right)\right)=S\left(x′;{ϕ\left(c\right):{m}_{C}\left(c\right)=1},{ϕ\left(ω\right):ω∈{J}_{A},{m}_{R}\left(ω\right)=1}\right)$，即只对掩码为1的组件和关系归一化。未审核关系既不作为正例，也不作为NONE负例；金标锚定仍不构成排除全部退化解的保证。

### 3.4.2 源文档归一化与参数更新

设源文档 $d$ 接受 ${m}_{d}$ 个视图。原文承担完整图生成及继承句子监督；增强文只作为输入视图，不将含未审核关系的输运图作为完整生成答案。头监督定义为

${L}_{heads,d}^{sup}=\frac{S\left({x}_{d},{G}_{d}\right)+\sum_{j=1}^{{m}_{d}} {S}_{{m}_{j}}\left(x{′}_{dj},{ϕ}_{j}\left({G}_{d}\right)\right)}{1+{m}_{d}}.$

成对项先在每个非空因素组内平均，再按同源接受视图平均。总损失为

${L}_{d}={L}_{ICIC}\left({x}_{d},{G}_{d}\right)+{λ}_{sup}{L}_{heads,d}^{sup}+{λ}_{C}{\hat{L}}_{C,d}^{align}+{λ}_{R}{\hat{L}}_{R,d}^{align}.$

默认 ${λ}_{sup}=1$、${λ}_{C}={λ}_{R}=0.5$。无变体时只保留原文对应项；有变体但无可靠关系时，关系对齐置零，组件学习仍可进行。接受视图已通过组件检查，被改写组件的 ${m}_{C}$ 均为1，因此计入 ${m}_{d}$ 的视图不会出现空组件项。批内按源文档平均，梯度累积末批按实际文档数归一化，不把接受变体多的源文档自动赋予更高权重。

按 $1+{m}_{d}$ 平均使每篇源文档的头监督总权重固定，代价是原文在头监督中的占比随接受视图数变为 $1/\left(1+{m}_{d}\right)$；原文完整生成损失 ${L}_{ICIC}$ 不受影响。完整筛选与因素掩码通常接受不同数量的视图，二者的比较因此同时包含这一占比差异，这是数据策略的一部分。成对学习消融固定同一批视图与掩码，不受该差异影响。

两个视图均保留梯度。生成和句子损失更新继承模块，组件与关系头及成对项通过输入表示更新全局LoRA；类型前缀门控的结论专项分支只由相应生成路径更新。基础权重冻结，辅助头在评价时移除。推理评分器另行训练，不使用这些辅助头的类别概率冒充完整对象正确率。

全文改写后所有标签都被确认的额外版本可以计算增强图生成损失，但须独立命名并控制更新量。本文默认不采用该版本，以免将未审核监督重新从生成目标引入。

## 3.5 算法及性质

算法3-1将增强构造和参数学习分为两个阶段。前一阶段在固定预算内生成并筛选文本变体，后一阶段按源文档归一化训练。两阶段的数据构造及损失计算均只访问训练划分；开发集的参数选择与停止规则按第二章2.5节执行，测试标签不参与上述过程。

算法3-1 关系影响域增强与成对学习

```text
输入：训练文档及金标图 D_train，数据协议，固定增强与语义验证模型，
      每文档尝试上限 B_try、接受上限 B_accept，训练更新上限 U，
      审核模式 mode ∈ {FactorMask, FullFilter}。
输出：训练后的端到端生成器 θ，以及增强样本、组件映射和来源记录。
01  检查训练划分、全文哈希分组、坐标和标签协议
02  for 每篇源文档 d ∈ D_train do
03    保留原文 x_d 和完整金标图 G_d；令 Views_d = ∅
04    按3.3.1固定中心及完整入源；不可处理则记原因并继续下一文档
05    建立 Ω(C_d) 并排除语义未知集合得到 Ω_sem，构造改写集合 A
06    构造完整影响域 D_A；令 attempts = 0
07    while attempts < B_try 且 |Views_d| < B_accept do
08      attempts ← attempts + 1；生成组件槽位的替换文本
09      回填全文、重新分词，建立全部组件的双射 φ
10      if 格式、槽位、坐标或端点检查失败 then
11        拒绝整个变体，记录原因及成本
12        continue
13      end if
14      检查全文角色与表达退化
15      if D_A ≠ ∅ then
16        if mode = FullFilter then J_A ← D_A；不可完整审核则拒绝本次视图
16a       else J_A ← 全部受影响正关系 ∪ 固定抽样内部及边界 NONE
16b       在 J_A 中排除已定义的语义未知因素，逐项核查原／新状态并建立 m_R
17      end if
18      if 组件含义变化／待定、结构失败，或完整筛选版本任一因素失败 then
19        拒绝整个变体，记录原因及成本
20        continue
21      end if
22      将全文视图、φ(G_d)、φ、可靠因素掩码和来源加入 Views_d
23    end while
24    保存 Views_d；集合为空时仍保留原文
25  end for
26  for step = 1, …, U do
27    按源文档等频取训练批次；读取原文及其已接受视图
28    依可见前缀门控，仅计算原文完整生成损失及继承句子监督
29    从输入表示计算原文可审核因素的头监督及变体掩码内的头监督
30    依 φ 计算可靠因素上的成对损失；无变体或空可靠域时置零
31    保留两个视图的梯度，按同源变体及源文档两级归一化
32    按3.4.2节的梯度路径执行一次反向传播；基础模型权重冻结
33    if 达到2.5节预先确定的停止条件 then
34      break
35    end if
36  end for
37  返回生成器及来源记录；开发评价和测试时移除训练辅助头
```

每篇文档的参考预算为最多四次尝试、最多接受两个变体，具体训练更新数由公共实验协议确定。参数学习在同一次反向传播中更新可训练参数：全局LoRA、触发的连续提示及辅助头按各自损失路径更新，结论专项分支由生成损失更新。无增强样本时保留原文监督；梯度累积的最后一个不足批次按实际源文档数归一化。

性质一：标注输运保持。 若可改写槽位互不冲突、$ϕ$ 为组件双射，且类型和每个完整关系因素均按 $ϕ$ 输运，则 $G$ 与 $ϕ\left(G\right)$ 的组件数、组件类型及带方向和标签的关联结构保持。证明为：双射保证每个原组件恰对应一个新组件；端点逐一映射保证每条关系及超边既不新增也不丢失，逆映射可恢复原图。该性质针对标注对象成立，不能证明改写后的自然语言仍支持这些标签。

性质二：单因素预测稳定的充分条件。 对某一因素，设原视图正确类别为 $y$，分布 $p$ 的间隔为 $δ={p}_{y}-{max}_{k≠y}{p}_{k}>0$。若增强视图分布 $q$ 满足 $∥p-q{∥}_{∞}<δ/2$，则 $argmaxq=y$。因为对任意 $k≠y$，${q}_{y}-{q}_{k}>{p}_{y}-{p}_{k}-δ≥0$。这只是逐因素条件，平均 JS 降低不意味着每个因素均满足该界，也不能使原先错误的预测自动正确。

两项性质解释了标签输运与预测约束的作用范围，不构成新的通用等变学习定理。本章约束的是辅助图因素分布，而非证明自回归生成的完整图分布严格等变。文本语义漂移、验证器偏差、金标噪声与候选宇宙外关系均可能破坏预期效果；最终判断仍以未参与增强的真实测试文本为依据。

## 3.7 本章小结

本章将局部改写后的监督保持分解为字符身份迁移、语义审核及可靠因素学习。组件双射保证标注对象可追踪，关系掩码使不确定监督不会重新进入增强侧损失，源文档归一化控制了视图数量造成的权重差异。模拟比较给出了整套训练配置的正向结果，但尚未在主要比较族内独立确认成对项的收益。教学示例已明确接口计算；真实增强记录、分层聚类审核及目标模型实验仍是验证这些方法效果所需的证据。
