# 七张方法图的重绘契约

本轮使用既有 Python 工作流，以 matplotlib 重绘方法示意图。读者为中文计算机学位论文读者；不将调用 nature-figure 等同于 Nature 投稿或实证认证。七图是方法说明，不是实验结果；不生成数据、不把构造片段改称真实案例。

|图|唯一要说明的关系|阅读顺序与各区域作用|边界|
|:--|:--|:--|:--|
|1-1|关系连接完整论辩组件|构造原文 → 跨度与类型 → 两条Support和一个NONE|NONE不画成已输出边；保留c2完整理由|
|1-2|两项工作处理同一依赖的不同阶段|共同依赖 → 训练监督保持／推理结构恢复 → 继承基础|不新增第三项研究，不把继承技术标成贡献|
|2-1|训练后的生成器连接两阶段|离线增强与学习 → 训练后生成器 → 候选初始化与修正|金标只在训练侧；辅助头测试时移除|
|3-1|影响域包含内部与跨边界的正关系和NONE|可改写区与只读区 → 受影响因素 → 标注输运与接受检查|位置类别不等于标签类别；图中只列部分组合|
|3-2|两视图通过共享生成器与对应因素学习|输入与监督分开 → 冻结／可训练参数 → 继承目标与新增头 → 联合目标|新增因素梯度不直接更新结论专用LoRA；金标不进入输入上下文|
|4-1|组件替换必须连同依赖关系整体判定|固定原文 → 新旧完整对象 → 关系重建 → 整图门 → 提交／回退|长跨度并不预设为正确；最小扩域只处理失效已选外部槽位|
|4-2|资源和状态约束决定评估提交及停止|初始化 → 冻结评分 → 批次 → 闭合评估 → 择优提交或继续／停止|no-op独立；失败计算仍计费；提交不重复增加尝试|

版式采用 schematic-led composite，各图为单个连续关系图，而非多个可比定量子图；自动面板对齐记录应为单轴不适用，节点对齐另按毫米网格核对。最终图宽157 mm，各图高度92–148 mm；正文标注8–9 pt，标题9–10 pt，任何PDF字形不低于5 pt。使用Arial Unicode MS保留中文和可编辑文字，SVG文本不转轮廓，PDF嵌入TrueType，PNG为600 dpi。

统一语义：蓝色表示训练相关路径，青绿色表示推理相关路径，灰色表示原文、既有模块或只读对象，橙色用于检查条件或待判定对象；同时用文字和边框区分类别，灰度打印仍可读。流程图实线箭头表示数据／表示，虚线表示控制／调用；论辩图中的实线箭头单独标明Support，NONE不画边。

术语固定为：关系影响域、成对学习、组件对应φ、端点依赖域、依赖闭合事务、原子提交、完整合法图、MCR、ICIC、全局LoRA、结论专用LoRA、NONE。沿用正文定义，不另造方法名。

全部源数据来自已给定论文机制与教学片段；统计单位、区间和重复次数不适用于方法示意图。四张定量结果图原字节保留。每次布局变更后重跑源代码检查、PDF字形检查、PDF碰撞检查，并逐区域与整图视觉复核；碰撞FAIL必须修复，WARN逐条说明。最终另核对Word中实际显示尺寸、图注和全部页码。
