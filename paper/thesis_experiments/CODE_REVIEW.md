# 实验实现审查记录（2026-10-13）

本记录针对本目录 0.1.0 代码及 `validation/source_snapshot.json`，参考论文版本为 `manuscript_review_test_20261011/protocol_identity_audit_20261012_v6/论文规范排版稿_v6.docx`。正文未修改，旧模拟实验未导入新训练或评价流程。

## 审查后修复的实质问题

1. **模块身份和训练来源**：提取器、盲审核模型、完整源组提案器、独立评分编码器分别配置。adapter 绑定基础模型文件身份；折外生成器及跨度头排除 held-out 源；评分拟合、校准和 policy 的来源清单必须齐全且互斥。
2. **校准分布**：评分拟合可联合 T0/T1 候选；校准逐生成器应用部署裁剪，不先合并候选。policy 只使用预声明的 T1 折外单池，冻结后供 T0/T1 共用。
3. **候选一致性**：源组提案目录包含跨度补充；裁剪使用同一原始评分排序，避免校准概率饱和改变排序；保护集合纳入快照摘要；不可变评分可以序列化和回放。
4. **增强条件和原生协议**：生成器获得完整类型、正关系、只读端点、UNKNOWN 例外和 NONE 补集定义；盲审请求仍不提供期望标签。AAEC stance 作为原生属性保留并输运，不补造成普通关系，也不新增 stance 预测成绩。
5. **可复现训练与执行**：评分头、跨度头在初始化前设置实验种子；生成逐文档/候选派生种子；失败不串用旧输出。checkpoint 身份路径、全部 CLI 参数及计划恢复的输入/配置/代码/输出摘要均核验。
6. **严格统计**：失败保持官方分母；完整源集合、方向、标签与原生边界共同计分；不存在强制 FP=FN。正式评价必须绑定输入哈希，计数必须是非负整数；Regenerate 未通过资源匹配就不能进入正式比较。
7. **风险与事务**：真实 HiGHS 小问题对照穷举、风险门保 TP、NoRisk 边界、依赖闭合、拆合、超时、原子回退和账本篡改均有测试。求解器可行解与已证明最优状态分开记录。

## 保留的明确实现选择

- I0 使用原生 BR-O 新移植，不宣称恢复历史原始检查点；G0 只作为共同初态。
- 局部默认最小 Graph.key，全局默认规范顺序优先保持 G0。论文两处三级破同分表述存在差别，代码通过配置和日志明确区分。
- 默认单卡 24GB、7B NF4、bf16、检查点化、单源微批/32 次累积；尚待真实 CUDA 验收。
- 自定义双分支 LoRA 使用 `ExtractionModel.from_adapter` 加载；checkpoint 不是可直接交给标准 PEFT 的单 LoRA 文件。
- 默认计划包含五种训练变体和主要推理消融；FullFilter 可通过增强 CLI 单独构造。外部 SOTA、QOS/DOS 完整系统和历史主表数值不在本实现中冒充已复现结果。
- Regenerate 需要完整真实 I1 计费凭证，默认关闭；当前没有服务器完整实验或等预算效果结论。
