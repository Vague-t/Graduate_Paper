## 2. 总体判断：最适合作为“操作说清楚”的样本

该稿以“针对什么问题，先做什么，再得到什么”展开方法。虽然也使用“有效”“充分”等常见词，但关键段落通常有明确操作主体和对象：映射实体类型、过滤低频组合、采样上下文、构造正负样本、编码查询和候选项、计算相似度。读者不需要先理解大量新造抽象名词，就能顺着流程看懂模型。

其价值还在于保留不占优的结果：主结果分析明确指出某些数据集落后于基线，再尝试解释。后续润色可以学习“直接说出差异”，不必每处都写成长篇防御性说明。不过样本中的原因解释是否有充分实验证据，仍应独立判断，不能一概继承。

## 3. 章节职责与两个方法章的差异

| 章节 | 样本组织 | 写作职责 | 可迁移规则 |
|---|---|---|---|
| 摘要 | 总问题 → 两项挑战 → SMiLE 和 ChapTER → 总结 | 用一条“异质信息融合”主线串起两项工作 | 两项工作是同一主题下的不同问题，不必硬说第二项是第一项的改进版本 |
| 第一章 | 背景 → 表示学习/异质信息融合现状 → 研究内容 → 章节安排 | 明确问题范围，并告诉读者两章分别处理什么 | 现状介绍要能导向本文选择，不必按国内/国外机械分组 |
| 第二章 | 任务定义 → 表示与融合方法 → 自监督学习 | 提供后续公式和实验设定需要的公共知识 | 公共定义放前面，方法章只补本章特有输入和符号 |
| 第三章 | 引言 → schema构建 → 多视图编码 → 多层级对比预训练 → 微调 → 实验 | 按“数据构建—表示—训练”流程说明静态图方法 | 若流程清楚，方法模块可直接做二级标题，无需额外套一个很大的“总体方法”节 |
| 第四章 | 引言 → 双塔模型 → 文本与模板 → 编码/前缀微调 → 负样本与损失 → 实验 | 把时序推理转为查询-候选匹配，再解释各输入和学习方式 | 整体任务转化先说清，随后沿着数据流往下讲 |
| 两章实验 | 任务数据 → 设置 → 对比 → 消融 → 性能分析；第三章另有可视化案例 | 验证各自提出的问题，不以小节数量显示工作量 | 哪一项设计需要解释，才安排对应分析 |
| 第五章 | 回顾主要工作 → 未来方向 | 把两项工作重新收束到全文问题 | 用已完成内容总结，用未完成问题提出展望 |

两个方法章的承接属于“研究场景扩展”：第三章研究静态图中的上下文与结构，第四章转向动态图中的时间与文本。并非所有论文章节都必须构成严格的算法递进或共享同一模型。

## 4. 自然且可检验的段落写法

### 4.1 章首说明这一章为什么出现

第四章开头先交代上一章处理静态图，再指出实际图谱会更新，继而提出本章要捕捉时序历史并与文本融合。值得学习的是清楚说出“问题哪里变了”，而不是反复写“在前文基础上进一步深入展开系统研究”。

### 4.2 问题动机用真实对象解释

§3.2 用同一人物具有演员、公民等不同类型的实例说明上下文差异，再引出 schema 的构造。该写法把“语义多样性”落到具体对象；后续模型润色宜保留最有解释力的案例，而不是用“多粒度、异质、复杂、高阶”等修饰词代替它。

### 4.3 一个操作段落可以按条件—动作—结果展开

§3.2 先说明实体可有多个类型，再说统计类型三元组频次、过滤低频组合、形成全局 schema。§3.4.1 先说批次大小限制负样本数量，再引入动态队列，最后说明队列不能过长的原因。

这给出一条软规则：解释某个设计时，优先写清它解决的实际障碍、做的具体动作和留下的限制。不强制每段都包含同样数量的句子，也不强制所有段落以“为了”开始。

### 4.4 公式之间用对象变化衔接

§4.2 按“编码查询/候选得到向量—计算余弦相似度—选最大得分”展开；公式之后的文字解释符号对应什么对象。§3.4 把正样本、负样本和损失分别说明，避免一次公式承担整套方法。

建议保留函数的输入输出、采样条件、共享/独立参数以及训练与推理差异。少用“严格”“完整”“一致”“可核验”等无新增信息的修饰，但不能删掉它们背后真正必要的条件。原公式在提取文本中有字符缺失，本次不对公式正确性作认证。

### 4.5 文献引用接在具体技术点上

样本常用“方法名[编号] + 它怎样建模”组织介绍；在采用 CompGCN、InfoNCE 或前缀微调等已有技术时，就近给出引用。可迁移为：引用应说明借用了什么或比较了什么，不是为整段泛泛的技术评价装饰。

本次没有逐条核验参考文献，不把这些文献号移植到新论文。后续润色只保留原稿有效引用，不编造新来源，也不改变引用所支持的主张。

### 4.6 图表与结果：先告诉读者比较什么

框架图前的段落说明图中的输入、编码器、训练目标，随后正文沿相同顺序展开。主结果分析先给总趋势，再点名重要例外；案例可视化先说明抽了哪些实体、怎样降维，再解释可见差异。

视觉观察：第 32 页框架图显示上下文层级与全局层级两个并列支路；第 50 页图4.1区分冻结/训练参数并显示查询、候选与历史输入关系。可学习“图上对象和正文对象对得上”，不照搬复杂图内的小字号和装饰图标。正式字号、字体、行距等仍由学校模板决定。

## 6. 成稿中不应复制的地方

- PDF 43 的消融分析写“各个模块的去除或者简化均会导致模型性能的下降”，但同页表3.5中去掉上下文对比后 FB15k 的 F1 从 90.76 变为 91.04。学习其解释消融定义的方式，不复制与表格不完全吻合的全称结论。
- PDF 59 中一些原因解释写得较确定。若没有直接诊断实验，后续稿应写为“可能与……有关”并说明观察依据，而非为了自然感把推测改成事实。
- “普遍优于”“先进”“优异”等词在样本中频繁出现。实际润色应尽量换为具名基线、数据集或具体指标差异，但不能替作者补造数值。
- 第五章将背景理论介绍列为工作的一部分，这是样本组织选择，不意味着每篇论文都要把综述写成创新贡献。
- 图中冻结/训练用图标辅助，文字过密时较难辨认。可借用层次和数据流，不复制视觉复杂度。

## 7. 原创示范改写（非原文）

### 示例一：用处理链代替抽象结论

自拟待改句：

> 该模块旨在面向不同层级信息的异质性特征实现多维语义结构表征的有效构造与协同融合。

自拟改写：

> 该模块分别编码实体的邻域结构和上下文类型，再通过对比学习使两种表示相互补充。

说明：说明谁被编码、怎样联系，不添加“显著提升”等未经提供的结果。只有方法确实如此时才可采用。

### 示例二：直接交代结果例外，保留推断身份

自拟待改句：

> 尽管必须承认本模型并非能够在一切条件下保证无例外地超越所有对照方法，但在某些受限设定中呈现的差异并不必然否定整体方案的可行性。

自拟改写：

> 模型在多数设置下取得提升，但在数据集 A 上仍低于基线 B。这一差异可能与输入截断有关，后续需要结合截断样本进一步分析。

说明：A、B 为示范占位，不是新增实验结果。改写删去辩护语，没有把“可能”删掉，也没有把未完成分析写成已完成。
