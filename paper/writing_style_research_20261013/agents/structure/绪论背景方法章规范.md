# 绪论、背景与方法章写作规范（两篇样本的交叉提炼）

版本：2026-10-13，结构组独立首轮；供主报告和后续 skill 选用。结论基于 `temporal_kg` 与 `contrastive` 两份已提供 PDF 的重点章节，不代表全校或全领域硬性规则。

## 1. 使用原则

本规范的目的不是减少方法严谨性，而是减少为了显得严谨而增加的重复声明、抽象套话和审计口吻。优先把动作、对象、条件和观察结果说清，再检查是否还需要限定语。

必须保留：原有事实、数值、方法条件、数据来源、模拟/构造/真实实验的区分、引用、确有影响的局限。允许压缩：重复的研究意义、重复的章节预告、没有新增范围信息的防御句、已由上下文明确的术语释义。不能把用户提供的成稿风格说成用户本人独有的写作声音。

证据定位见同目录两份逐篇规范的 T01–T15、C01–C16。所有物理页锚点均来自对应 PDF，结构预检 PASS；没有由样本推断字号、页边距等学校强制参数。

## 2. 章节分工：同一问题在不同位置承担不同任务

| 位置 | 应回答的问题 | 可以保留的信息 | 常见过度写法 |
|---|---|---|---|
| 绪论背景 | 为什么这个具体问题值得做？ | 对象、任务、实际障碍、必要例子 | 从人工智能发展史写起，反复强调重要意义 |
| 国内外研究现状 | 已有工作怎样处理，本文接在哪？ | 分类依据、代表方法、相关差异 | 文献逐篇流水账；不限定范围地否定所有现有工作 |
| 研究内容 | 本文究竟做了哪几件事？ | 问题—方法动作—验证方式的对应 | 按模型部件堆创新点；把写背景和调参数都列成创新 |
| 章节安排 | 到哪里找什么？ | 章节职责和相互关系 | 把贡献再完整写一遍 |
| 背景章 | 读方法章之前必须知道什么？ | 公共定义、关键技术、会复用的符号 | 教科书式百科堆积；重复绪论现状评判 |
| 方法章引言 | 本章具体解决哪一步困难？ | 前章已解决什么、新增困难、设计思路 | 全文背景重讲一遍；假装每章都重启一个新课题 |
| 方法主体 | 输入经过什么操作变成输出？ | 数据流、关键模块、目标、训练和推理 | 抽象目的很多，实际操作和接口很少 |
| 本章小结 | 本章最后得到什么？ | 完成的设计、核心观察、必要承接 | 逐小节再摘要一遍，重复所有结果数字 |

这一分工有两份样本支持：temporal_kg PDF 9–11、20–25、36–39；contrastive PDF 11–12、17–21、31–38。它是内容职责建议，不是每篇都必须有这些标题。

## 3. 绪论规范

### 3.1 从研究对象收束到缺口

推荐阅读顺序：研究对象及任务 → 现有做法 → 本文关注的不足 → 拟采用思路。一个读者能复述的小例子，通常比连续的“高维、异质、复杂、多源”更有帮助。

支持证据：T03（PDF14–15，四元组例子）；C03（PDF13–14，从图谱表示到信息融合和时序问题）。

反例处理：不能把“需要一个例子”强制成每节都编例子；资料中没有真实案例时，可明确标为“示意”，不得写成实验观察。

### 3.2 文献按本文要解决的差异分组

先说明分类依据，再用代表方法解释其处理方式，最后指出本文关心的剩余问题。分类可按模型范式、信息类型或任务设定，不必固定为“国内研究”“国外研究”。

支持证据：T04（PDF17–20，图结构/语言模型/应用）；C04（PDF17–19，表示学习/异质信息融合后接研究内容）。

例外：若学校明确要求国内外分节，应遵守；若现状与背景章部分重叠，应让前者重在“研究发展与差异”，后者重在“怎么计算与怎么用”。

### 3.3 贡献写成完成的工作，不写成赞美词

优先用“提出/设计/构建 + 对象 + 关键做法 + 作用位置”描述；结果另用实际证据支持。“新颖、高效、可靠、系统”不是贡献内容本身。

允许两类工作关系：

- 研究目标递进：由预测准确性拓展到解释生成；来源 T12，PDF51–54。这不自动意味着第二项方法继承第一项算法。
- 场景扩展式：先静态图，再动态图；来源 C13，PDF49–50。

不要为了使两章看起来有联系而补写不存在的算法继承、共享参数或互补性结论。

## 4. 背景章规范

### 4.1 只讲后文要用的公共知识

先统一任务、输入输出、评价设定和关键符号；随后介绍支持后续方法的技术。每个技术段落应让读者明白：它做什么、核心计算是什么、后文在哪里会用到。

支持证据：T06–T07（PDF25–31，外推定义与微调技术）；C05–C06（PDF21–22、29–30，任务区别和对比学习）。

不强制删掉所有基础解释。新读者理解方法所需的内容不是啰嗦；与后文无关联的百科背景才应优先压缩。

### 4.2 定义集中，使用就近

公共符号首次出现时解释，方法章只补新符号或改变的条件。涉及未见实体、时间可见性、样本集合等设定，不应用“自然化”作为删除理由。

对已定义概念可简短承接：“沿用第二章的外推设定，本章……”；只有本章任务确实变化时才重新定义。temporal_kg PDF25与36重复任务定义提示了可压缩空间；contrastive PDF21–22与54体现一般定义和本章具体任务的层次区别。

### 4.3 公式要承担解释任务

公式不是严谨性的装饰。先给计算目的，再给公式，再解释新符号和结果的用途。连续公式之间最好能看出对象如何变化；若只是已有基本操作且公式不能增加清晰度，可用准确的文字说明。

支持证据：T10（PDF39，频次→加权→归一化）；C14（PDF51，编码→相似度→排序）。此规则不规定每式前后几句，也不强制所有内容都用公式。

## 5. 方法章的三种可选组织

### 模式 A：整体模型下设模块

适用于一个模型内若干组件共同产生输出。

> 本章问题 → 本章新增定义 → 整体框架 → 模块说明 → 训练与推理 → 实验与分析 → 小结

样本：temporal_kg 第三章，PDF33–50。整体框架内有结构语义模块和历史频次模块，最后明确输出融合。

### 模式 B：按处理链直接分节

适用于数据构建、表示、采样和训练形成清晰先后关系的工作。

> 本章问题 → 输入或数据构建 → 编码 → 学习目标 → 推理/微调 → 实验与分析 → 小结

样本：contrastive 第三章，PDF31–48；第四章，PDF49–67。无需为了形式完整额外增加一个与后文重复的“方法总述”大节。

### 模式 C：新数据/基准与新模型并列展开

适用于数据构建本身是本章主要工作，且模型依赖它进行训练或评价。

> 新任务定义 → 数据/基准构建与质量控制 → 模型方法 → 实验 → 小结

样本：temporal_kg 第四章，PDF54–61。必须分清原始数据、自动生成、人工筛选和模型输出；不能把数据处理的真实执行等同于主模型实验已经完成。

上述三种只是结构选项。先看实际工作，再选最省重复、最便于跟随的一种，不以章节对称或小节数量为验收条件。

实验位置另行选择，不受上述方法内部组织方式限制：可以在每个方法章内分析，也可以在两方法章后统一设置实验章。后一种布局由格式组的 `transformer` 样本提供，结构组在交叉核对时补读了其 PDF 物理 7–9 页目录及 47 页第五章开头：第三、四章写方法，第五章统一实验。这里补充布局选择，不把两篇独立研究的来源范围改称三篇全文研究。

## 6. 段落层面的可执行润色顺序

1. 标出该段要解决的问题：定义、动机、操作、结果还是解释。
2. 圈出真正有信息的主体、动作、对象和条件。
3. 合并意思相同的目的句，删去空泛的重复修饰。
4. 将抽象名词串改为实际动作；若无法落到动作，先向作者确认，不擅自编方法。
5. 核对信息有没有变强：相关不能改成因果，可能不能改成确定，示例不能改成实测。
6. 读一遍是否能自然接到上下段；不按统一句长、段长或固定连接词改写。

与其维护“禁词表”，不如判断词是否在当前句子里增加必要信息。“需要指出”“值得注意”“有效”不是绝对不能用，但连续使用且不增加含义时应改。

## 7. 原创示范（不是样本原文，不可当实验结果）

### 7.1 章节承接

自拟待改：

> 在前文形成的完整研究框架基础上，本章进一步围绕复杂场景下的多维知识协同机制展开深入而系统的研究。

自拟改写：

> 上一章研究固定图谱中的结构与上下文信息。本章考虑图谱随时间更新的情况，重点处理历史事实如何与文本一起用于预测。

改写意图：直接交代场景变了什么。若前后章节实际不是这种关系，不能借用此承接。

### 7.2 方法条件

自拟待改：

> 为避免对实验边界产生任何可能的误解，有必要再次明确，此处候选构造严格限制在当前预测可获得的信息范围内。

自拟改写：

> 候选由当前输入生成，不使用测试标签；训练阶段的正负样本构造见下一节。

改写意图：压缩语气，保留关键信息。只有真实流程确实满足该条件时才能写；若源稿标为模拟或依赖金标构造，必须如实说明，不能靠改写消除事实差异。

### 7.3 给公式搭桥

自拟待改：

> 在相关理论约束下，为进一步实现表示空间的高质量匹配，定义如下形式化评分机制。

自拟改写：

> 得到查询向量和候选向量后，使用余弦相似度计算二者的匹配分数：

改写意图：让读者知道公式的输入和目的；不添加不存在的理论保证。

## 8. 后续润色验收

执行范围跟随用户请求：只润色一段时，核对该段及必要相邻定义/引用；请求章节重组时，才使用整章职责检查。以下不是每次润色都要启动的全文审计清单，发现来源矛盾时标记待确认，不替作者补实验或擅自选一版事实。

- 是否不看作者解释也能回答“这一章解决什么、输入什么、做什么、输出什么”？
- 绪论、背景、章首和小结是否各有职责，而非同一段话换词重复？
- 每张关键图是否被正文引出，图中名词是否与正文一致？
- 新符号是否就近说明；影响复现的条件是否保留？
- 是否将“理论上保证”“严格证明”等词留给确有依据的地方？
- 是否删除了无信息的反复辩护，而没有隐藏真实局限和证据身份？
- 是否没有新增数字、参考文献、实验完成状态、机制结论？
- 是否承认样本中的负面结果和写法缺点，不因“已过审”而照单全收？

这是一套清晰表达规范，不是人工写作鉴定工具，也不用于保证任何检测器结果。
