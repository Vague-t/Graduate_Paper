# 中文学位论文自然表达

把论文写得准确、具体、顺畅，像作者在清楚地解释自己的研究。参考成熟论文的组织方式，不模仿某位作者，不把“自然”理解为口语化、删掉必要条件或规避检测。

## 范围与参考

先看用户指定段落及必要的相邻上下文，识别章节任务和修改范围。默认做语言与局部组织调整；全文重构、技术修正、重新评审和补做实验不是普通润色的附带任务。

- 做实际润色前：读 [写作逻辑与文体规范](references/logic-and-style.md)，按本次范围处理全文、章节、段落、句子与用词；其中有样本依据、判断方法和四个维度的示范。局部任务不因此扩大到全文。
- 改具体章节：另读 [各章节写作规范](references/chapter-guide.md)，按对应章节选择写法；不必套用所有章节要求。
- 处理生硬、重复、晦涩的表达：读 [自然表达与改写示例](references/natural-prose.md)。示例展示判断，不是替换词表。
- 改标题、图表、公式及实验呈现：读 [格式与实验呈现](references/presentation.md)。学校现行模板优先，示例论文不是格式标准。
- 需要追溯规范来源时：读 [样本与适用边界](references/source-basis.md)。日常润色不要求重读样本论文。

## 编辑原则

### 从逻辑到表达，而不是从同义词替换开始

| 尺度 | 先检查什么 |
| --- | --- |
| 全文 | 问题、设计、证据与结论是否对应；几项工作的关系是否真实 |
| 章节 | 本章回答什么问题，定义、操作与结果按什么依赖展开 |
| 段落 | 中心是否清楚，段间是否推进；按问题变化拆并，不固定句数 |
| 句子 | 主体、动作、对象及条件清楚；观察、解释、转折与步骤不混写 |
| 用词 | 技术名称稳定，动词准确；修饰与结论强度有具体依据 |

在授权范围内先理顺信息，再调整句段节奏，最后改用词。信息密度看有效信息与理解成本，不以压缩比例衡量；必要的定义、条件和例子可以展开。不默认向用户展示分析表，也不因发现总体问题而擅自重构全文。

### 先保住信息，再调整表达

保留方法名称、符号、数值、单位、指标方向、比较对象、实验条件、数据来源、引文与其所支持主张的对应关系。区分已完成、计划、模拟、估算和假设。不能把“未显著”改成“有效提升”，也不能为句子完整而补造机制、数据或文献。

这是轻量的前后对照，不要求每次生成事实表或研究审计报告。原文存在会影响改写的歧义时，先完成无歧义部分；把具体疑点放在正文外的简短说明中。不要用新增的免责声明填补没有发生的研究审查。

### 以对象和动作组织句子

说清“谁对什么做了什么，为什么需要这样做”。优先使用能准确描述过程的动词，展开只有命名而没有解释的抽象表达。专业术语有明确含义时保留，不为了浅白而改掉技术名称。

句长随信息变化。先修饰语归属和因果层次，再决定拆句；短句也能承载复杂内容，不强制每句或每段长度。允许“本文”“该模型”“结果表明”等普通学术表达，避免机械换同义词。

### 让段落完成一件事

段落要有可辨认的中心，并保留必要推导或例子。去掉与前后段重复的背景和总结，不把每段都写成“首先—其次—最后—综上”。已有自然、准确的句子可以不改。

衔接要落在具体信息上：前一段指出的困难，如何引出下一段设计；一张表中的差异，为什么引出下一项分析。不要只靠“此外”“进一步而言”制造衔接。

### 必要限定放在读者需要的位置

同一实验条件可在小节开头集中交代；局部差异、推测和例外仍在相应句子说明。摘要、图注、结论等可能独立阅读的部分，需要保留足以避免误读的关键条件。不要为了少重复而把这些部分变成无条件断言。

结果观察直接写，原因解释按现有证据写。已确定的操作不必反复“可能”“在一定程度上”；尚未验证的原因不能去掉推测语气。局限应具体，不在每段补一句“不能据此证明普适有效”。

## 交付

按用户要求返回替换稿、对照稿或文件。未指定时，短段直接给润色后文本；长章提供改稿和少量重要改动说明。只有真实存在的待确认点才单列，不额外附上评分、长篇审计或一套新的写作任务。

文件润色保留原版本，遵守目标文件的样式、编号和交叉引用。若实际修改 Word、PDF 或 LaTeX，按对应文件工作流验证版式；本 skill 本身不声称已完成排版验收。

交付前对照原文确认：信息没有增加或变性，指代与逻辑更清楚，语气符合该章节，必要限定没有丢失。无需为了满足某种“自然度”字数、标点比例或词频而强行改写。
