## 一、最终判断

**值得继续一次有明确停止条件的验证，但目前不应把新路线认定为已成立的第二创新，更不能认定两项创新已经达到目标质量。**

这次不是只给计划：已经下载数据、训练轻量模型并完成 AAEC/CDCP 的真实训练集内部审计。结果把问题分得更清楚了：

|判断对象|本轮结论|依据|
|---|---|---|
|能否从文本提出足够多的正确跨度候选|有明确积极信号|初始预测之外追加 128 个候选，AAEC/CDCP 精确跨度覆盖率为 95.84%/96.82%|
|候选出现后，当前动作能否恢复它|尚未闭环|单步可合法补回的初始遗漏跨度仅占全部遗漏的 45.50%/9.20%；多数 CDCP 正确候选与多个错误碎片重叠|
|评分是否已能可靠选择主动恢复动作|未通过本轮“进入完整方法开发”的证据门槛|最终接受的 181 次修改全部是删除，没有增加任何真阳性组件|
|完整组件—关系协同修正是否有效|尚未验证|未运行错误端点下的关系重建、完整事务或强模型对照|
|第一项创新是否安全|需要收窄并补关键对照|发现直接近邻 QOS/DOS；“结构保持改写”本身不再足以区分工作|
|能否保留两个研究贡献方向|可以，但不是靠拆模块凑数|训练期显式关系约束增强，与推理期依赖闭合修正，问题、算法和归因实验应分别成立|

因此，研究决策是：**继续验证候选—动作—接受决策这条链；暂缓把 0918 设计升级成正文已验证主方法；第一创新同步加入 QOS 对照。**不建议直接回到旧评分器开放组件修改，也不建议现在投入全套大模型调参。

上述否定结论只针对“现有证据是否足以支持主张”。本轮是非常弱的线性基线，不能据此证明更强候选器或神经评分器也必然失败。

## 二、最新文献对创新边界的实际影响

### 2.1 第一创新：新增一个不能回避的直接对手

[Bao 等，EMNLP 2025：Exploring Quality and Diversity in Synthetic Data Generation for Argument Mining](https://aclanthology.org/2025.emnlp-main.1351/)<!--ref:bao2025qos--><!--anchor:section:4.1--> 已提出 QOS：分离上下文和组件、以占位符回填改写内容并继承标注。其 §4.1 明确说明，改写提示**不显式提供论辩关系**，而依赖语义保持间接保留关系；论文还在 AAEC、CDCP 等数据上进行增强实验。

这意味着，“组件改写—回填—重算边界—继承标签”与已有方法有实质重叠。可进一步研究的差异应落在：**显式提供有向关系及其类别，以结论邻域限制改写范围，并检查局部改写对跨边界关系的影响。**这是可检验的差异，不是已经证明的新颖性或优越性。

不能只补这篇引用而不做对照。若“QOS + 同样筛选预算”已经取得相同收益，原第一创新需降格；若显式关系条件和局部选择各有稳定增量，第一创新才更有说服力。

### 2.2 第二创新：不能再用宽泛的“同时改组件与关系”定位

|最近邻|已核对的相关能力|本方案必须证明的不同之处|
|---|---|---|
|[Niculae 等，ACL 2017](https://aclanthology.org/P17-1091/)<!--ref:niculae2017--><!--anchor:section:Abstract-->|组件类型与关系的结构化联合学习|不是首次联合；比较同评分器联合解码与预测后的受限事务|
|[Das 等，AASP 作者预印本](https://arxiv.org/abs/2510.16363)<!--ref:das2025aasp--><!--anchor:section:Abstract-->|自回归端到端论辩结构预测|不是首次设计构图动作；关注修改既有组件后证据失效与接受决策|
|[Sun 等，FEVER 2026](https://aclanthology.org/2026.fever-1.1/)<!--ref:sun2026weak--><!--anchor:section:3-->|边界改进与弱标签关系去噪|训练期去噪和推理期事务不能混称；IoU/条件分类成绩不能直接比较严格端到端 F1|
|[Bąba 与 Chudziak，2026 作者预印本](https://arxiv.org/html/2606.16047v1)<!--ref:baba2026gate--><!--anchor:section:5.3-->|金标准边界下的关系置信度门控辩论|门控已存在；必须在预测端点下测主动恢复及误改，而非只做关系分类|
|[Tran 等，ArgMining 2026](https://aclanthology.org/2026.argmining-1.11/)<!--ref:tran2026instruct--><!--anchor:section:Abstract-->|约束候选空间与困难样本选择性辩论|不是首次候选约束加反馈；其段落级设定不同于精确跨度图修正|
|[Xiao 与 Li，UAI 2026 ARGUS](https://proceedings.mlr.press/v337/xiao26a.html)<!--ref:xiao2026argus--><!--anchor:section:Abstract-->|形式论辩框架中的最小改动修复|形式可接受性不等于自然文本抽取正确；不借用其最优性保证|

本轮找到了 Tran 等的正式 Anthology 单篇记录，补上 0918 记录中“未确认单篇出版”的缺口。AASP 和置信度辩论仍按本轮取得的作者版本使用，不额外猜测出版状态。

**综合推断：**组件—关系的联合处理在技术上可行，但新意只能建立在一个更窄的研究问题上：当组件存在性、边界或类型改变时，怎样评估包括受影响关系在内的完整修改，并在可控预算下取得比重新预测、简单剪枝、顺序修正或全局解码更好的收益—误改—成本折中。

该推断不等于“检索证明此前无人做过”。本轮是针对性检索，非穷尽性系统综述；来源细节见[文献补充记录](/Users/channtang/Downloads/paper/research_0920/文献补充与判断边界.md)。

## 三、实际预实验做了什么

运行命令：

```sh
python3 research_0920/run_feasibility.py --datasets aaec cdcp --split train-dev --max-minutes 20
```

运行成功，训练与诊断约 **29.03 秒**，单线程 CPU，进程峰值 RSS 约 **714.8 MiB**。这不含资料调研、环境安装和脚本开发时间。没有调用在线模型、没有付费训练。日志出现多次达到迭代上限的收敛警告，结果因此只作预算受限线性诊断；没有为追求好成绩临时增训或重跑。

- 不给原始语料附加新许可证，也不将其推送 GitHub。正式发布应另核对原许可与再分发权限。

### 3.2 模型与验证对象

使用词汇、上下文、位置、边界特征的稀疏线性模型。BIO 模型产生初始组件，边界模型从全文提出新跨度，追加小范围边界扰动。评分器以三折交叉拟合候选训练，包含真实预测产生的 NULL 负例。校准和接受阈值仅在校准部分选择。

主实验只测组件编辑评分，**没有实现 0918 的完整关系能量、组件概率门槛、闭合事务和 ILP/beam 内层求解**。关系模型仅作给定金标准组件的补充诊断。故它是路线预实验，不是 0918 方法复现，更不能与正文历史分数比较。

另一个重要限制：初始 typed component F1 仅为 AAEC 25.42、CDCP 4.89，尤其 CDCP 严重过度分割。它们并不代表论文原有 LLM 模型的质量或错误分布。这里证明“有信号/有失败模式”，不能量化最终方法的潜在增益。

## 四、闸门一：候选可恢复空间

### 4.1 候选池覆盖有积极结果

下面的“+N”是**保留全部初始跨度，再增加最多 N 个候选**，不是候选总数。所有候选来自文本预测，不往审计候选池注入金标。

|新增预算|AAEC 精确跨度覆盖|AAEC 关系全部端点覆盖|CDCP 精确跨度覆盖|CDCP 原生关系全部端点覆盖|
|---:|---:|---:|---:|---:|
|0|42.49%|25.36%|15.77%|2.50%|
|64|90.16%|87.72%|94.19%|89.50%|
|128（预先固定的主预算）|95.84%|95.22%|96.82%|94.50%|
|256|97.57%|97.45%|98.62%|98.00%|
|512|98.68%|99.04%|98.89%|98.00%|

主预算下，每篇平均候选数约 153.6/151.7。95%/90% 是本轮运行前设置的研究决策参考线，不是领域通行标准。按这一粗筛，**池级覆盖达到继续验证条件**。

但仍有三点不能跳过：

1. 这里只检查跨度是否存在，类型未预剪枝，关系标签也未预测；不能叫组件 F1 或关系 F1。
2. 这是必要端点覆盖，不是满足所有图约束后能同时恢复的关系比例，更不是 oracle 最优分数。
3. 95.84% 的整体均值掩盖 AAEC MajorClaim 覆盖仅 89.26%；CDCP Policy 为 93.20%。真正要强化的类别仍需单独检查。

### 4.2 更关键的问题：池里有，不等于当前动作能拿到

对保存预测进行事后只读审计：若新正确跨度与两个或更多现有组件重叠，“插入”和“替换单个组件”的合法性检查都会挡住它。

|遗漏恢复漏斗|AAEC|CDCP|
|---|---:|---:|
|初始预测缺失的真实跨度|567|609|
|这些缺失跨度中，已在 +128 池出现|526（92.77%）|586（96.22%）|
|其中可用一次合法插入/单组件替换补回|258|56|
|占全部初始缺失跨度|45.50%|9.20%|
|已入池但与多个现有组件重叠|268|530|

以上可达性仍未要求通过评分门槛或恢复关系，属于乐观的单步动作诊断。它不是多步搜索的不可达证明：多次删除后再插入可能可达，但会消耗预算，且途中分数门槛可能阻断路径。

**这使 0918 的“Split/Merge 暂不进入主方案”需要重新审视。**不能直接用本弱模型断言真实 LLM 一定需要它们；但在真实初始预测上查清过度分割比例前，不应默认单组件替换已经覆盖主要错误。

### 4.3 下一版方法需要补的定义

建议把可恢复性拆为三个独立指标：

- `PoolRecall`：正确跨度/类型状态是否出现在冻结候选空间。
- `ReachableRecall(B)`：在合法动作、编辑规模和 B 次预算下，是否存在可达修复序列；有限 beam 搜索所得只能称已找到的可达下界，不能称精确上界。
- `AcceptedRecovery`：评分器实际接受后新增的正确组件和关系，以及破坏的正确项。

建议候选事务扩展为**有界局部重分割**：将同一小片段中的少量旧组件整体替换成候选组件集，再重建所有受影响关系。Merge/Split 是这一事务的特例，不单列新创新。编辑规模上限、搜索预算和分数比较仍须显式固定；局部组件数量变多不能靠改分母获益。

注意成本：主预算若枚举所有有向跨度对，AAEC/CDCP 平均约 2.35 万/2.32 万对每篇，尚未乘端点类型组合。候选覆盖容易提高，但关系评分成本不是免费；任何 pair 剪枝都必须重新审计关系可达率。

## 五、闸门二：评分器能否区分好修改和坏修改

### 5.1 总 AUC 很高，但不能据此宣布成功

|指标|AAEC|CDCP|
|---|---:|---:|
|审计修改总数|14,148|24,780|
|有益 / 中性 / 有害（按文档 typed F1 差分）|1,665 / 7,327 / 5,156|1,473 / 20,797 / 2,510|
|有益 vs 有害 AUC，排除中性|0.9791|0.9950|
|有益 vs 其余 AP，保留中性|0.7738|0.4906|
|最终接受修改数|66|115|
|接受动作|66 次删除|115 次删除|
|接受后的 TP 增量|0|0|

为何 AUC 可以如此好看？这个初始模型有很多明显错误碎片，删除它们相对容易；大量“错改成另一种错”的修改是中性，在有益/有害二分类 AUC 中被排除了。AUC 描述的是给定标签与候选分布下的排序，不自动说明能选出有价值的新组件。

动作分层进一步揭示问题：

|动作|AAEC 有益修改数 / AP|CDCP 有益修改数 / AP|
|---|---:|---:|
|插入|28 / 0.2012|无合法插入候选，不能评估|
|删除|1,328 / 0.9745|1,389 / 0.5108|
|改类型|79 / 0.0293|28 / 0.0017|
|改跨度|230 / 0.1025|56 / 0.0621|

CDCP 的改类型 AP 甚至低于其约 0.0025 的有益候选比例参考值；不能将总体 AUC 外推成可靠类型修正。该比较不是正式随机策略实验。

### 5.2 实际收益来自减少假阳性，不是恢复遗漏

下表 F1 以 0–100 报告；增量单位为百分点。阈值在校准集选定为 4.0，审计后未调整。区间采用固定预测、1000 次文本组配对 bootstrap；不覆盖训练随机性。

|设置|AAEC|CDCP|
|---|---:|---:|
|初始组件 F1|25.42|4.89|
|接受一次修改后 F1|26.06|5.06|
|净增量|+0.64|+0.17|
|95% 区间|[+0.58, +0.71]|[+0.12, +0.22]|
|同阈值禁止删除后的增量|+0.22|0.00|
|禁止删除后的 95% 区间|[0.00, +0.52]|[0.00, 0.00]|

删除后的假阳性分别减少 66/115；真阳性和假阴性均不变。因此即使净 F1 区间不含零，也只支持这个弱基线上的删除收益，不能支持“找回遗漏组件”。

不允许删除时，AAEC 接受 33 次修改，只有 3 次提高文档 F1，30 次中性；CDCP 不接受修改。阈值并未针对这个消融重新校准，所以它是固定规则压力测试，不是非删除策略的最佳可能表现。

候选并非完全没有好动作：事后金标诊断发现，AAEC 有 65/66 篇、CDCP 有 52/116 篇至少存在一个有益非删除动作。若每篇用金标挑选文档 ΔF1 最大的非删除动作，汇总组件 F1 为 30.28/7.85。这只是不可部署的局部 oracle 诊断，不是语料 micro-F1 的严格最优上界，也不意味着模型能达到；它说明“有动作但评分选不中”也是实质瓶颈。

这里还有一个指标设计陷阱：一个文档若 TP=0，删掉假阳性后其文档 F1 仍为 0，但语料级 micro-F1 可能改善。CDCP 的 62 次“中性”已接受删除属于这种情况。后续训练修改判别器应同时记录 ΔTP、ΔFP、ΔFN，不能把文档 ΔF1 的中性机械等同于对语料无价值。

### 5.3 关系评分只能给出有限积极信号

|给定金标准跨度和类型的补充任务|AAEC|CDCP|
|---|---:|---:|
|候选有向对|11,602|5,678|
|有关系比例|5.40%|3.17%|
|关系存在性 AP|0.6094|0.3161|
|带标签正关系 micro-F1|43.70|13.79|

CDCP 审计集有 19 条原生多前提关系；补充分类任务排除这些关系及其投影对，不把它们当成 NONE。200 条原生关系中，分类器实际可评价的单前提正对为 180；除多前提外，还存在投影屏蔽影响，不能简单以 200−19 推算其分母。

此结果只说明局部文本特征有一定关系识别信号。**没有测错误组件端点、关系事务得分变化、关系误改率或完整端到端关系 F1。**原生超边、展开二元边、合并源跨度三种协议不能混报；正式论文应选定并对齐文献，再给另一协议补充结果。

### 5.4 对评分设计的具体建议

1. **先换真实错误分布，不先堆复杂评分公式。** 使用论文生成器或有竞争力的神经抽取器的 OOF 预测，保留原始解析失败、错边界、错类型和漏组件。当前 CDCP 4.89 的初始 F1 不适合作为最终机制证据。
2. **评分器需要面对“另一种错误”，不仅面对明显错误。** 构造同一输入、同一初始图上的有益/中性/有害事务候选；训练阶段可以借金标打标签，推理输入禁止使用金标。报告每类动作自然基率和 hard negatives。
3. **文本分类校准与编辑收益校准分开。** 温度缩放只能作为起点，不能证明概率或 ΔJ 已对应实际净收益；[Guo 等，ICML 2017](https://proceedings.mlr.press/v70/guo17a.html)<!--ref:guo2017--><!--anchor:section:Abstract--> 不提供本任务的风险保证。
4. **先保留 0918 的固定空间能量作基线，再验证事务收益排序。** 可加预测 ΔTP/ΔFP/ΔFN 或好/中性/坏的辅助头，并明确选择代理目标。不应仅凭本轮删除占优就断言能量形式数学上错误，也不应未经实验证明就改称“可靠风险保证”。
5. **必须有简单置信度剪枝基线。** 若所有收益都可由删低置信组件获得，事务机制应降格为工程实现，不能用复杂名字替代机制贡献。
6. **同时统计正确组件保护和关系连带损害。** 组件改对但丢失正确关系、组件改错却通过删边提高局部分数，都应计入净修复与误改，而非只看修改成功例。

## 六、最终两个创新点该如何构成

### 创新一：显式关系约束的结论邻域局部增强

建议研究命题：**在增强预算相同的情况下，显式约束结论邻域中的关系，并控制局部改写对全文标注的一致性，能否比结构感知整篇改写更有效地改善组件与关系抽取？**

闭环应是：

> 关系条件可能在改写中丢失 → 显式给出局部有向关系并限制变化范围 → 检查内部及跨边界关系的标签保持 → 通过匹配预算实验检验增量，而非将所有全文复制视为有效少数类增强。

与 QOS 的关键差别应由“显式关系条件”“局部选择”“跨边界语义检查”分别消融证明。单独一个“选 Claim 为中心”是容易被评为启发式的小改动；如果这些机制没有独立收益，当前第一创新不足以支撑用户要求的质量目标。

还应纠正动机：本轮读取的官方训练部分统计如下。

|数据|各类组件数量|
|---|---|
|AAEC 322 篇|MajorClaim 598；Claim 1,202；Premise 3,023|
|CDCP 580 篇，排除 00411|Value 1,686；Policy 658；Fact 653；Testimony 873；Reference 31|

AAEC Claim 少于 Premise，但 CDCP Value 是最多的类别，Policy+Value 合计约 60.09%。**不能把两套数据统一描述为“结论都是长尾类别”。**Value/Policy 也不是天然等价的 AAEC Claim 标签。更稳妥的动机是结论及其关联关系的错误影响、表达多样性和标签保持风险；少数类说法只在具体数据和粒度下成立。

拟合子集中 AAEC MajorClaim 357 个、原生 R 关系关联数为 0。这是当前标注协议的性质，不是模型漏连；不要为了制造“中心性”把 stance 属性偷偷转成关系。

**最低必要对照：**无增强、QOS（按原实现协议）、QOS 加同预算筛选、随机中心局部改写、结论中心但无显式关系条件、完整局部关系条件增强。控制源文档、接受样本量、实际生成 token、训练更新数；过滤失败率及人工抽检误标率单独报告。若引用作者生成数据，须先验证划分无泄漏，不能与自己新增样本的训练预算混用。

### 创新二：依赖闭合的组件—关系事务式修正

建议研究命题：**当组件状态变化会使关系端点及其证据失效时，将局部重分割/重标注及受影响关系重建作为一个整体接受，是否比顺序接受或重新预测更可靠且成本可控？**

闭环应是：

> 初始组件错误限制关系空间 → 独立文本候选补充潜在正确状态 → 有界动作真正可达 → 受影响关系全部失效并重评分 → 事务整体比较、接受或回退 → 严格端到端收益与误改检验。

这是一项方法贡献。候选器、评分头、门槛、回退、缓存更新和审计指标是它的组成部分，**不能分别算成多项创新，也不能把“候选审计”和“评分验证”算成论文另外两个创新。**

最低必要对照应包括：固定初始图不修改、仅置信度剪枝、同评分器关系修正、组件后关系的顺序修正、同候选同评分器的全局/预算匹配联合解码、完整事务。关系参数、候选空间和初始生成器不同的对照只能解释系统差异，不能证明事务机制。

正式结果应同时满足：主动恢复组件而非只删错项；带预测端点的关系指标不被牺牲；对强基线有可重复净收益，或在相近质量下有清楚的误改/成本优势。无需预设必须超过某个固定百分点，但必须超过随机波动并解释收益来源。

### 两者的独立性与统一性

|维度|第一创新|第二创新|
|---|---|---|
|处理阶段|训练数据构造|推理后的结构决策|
|核心失败机制|改写表达变化导致关系标签失真、监督低效|组件改变后关系证据过期、局部接受不一致|
|独立验证|固定推理器，比较增强策略|固定生成器和候选池，比较修正策略|
|独立产出|带质量记录的增强方法与监督增量|可审计的事务算法、可达性和收益—误改分析|
|共享问题|组件错误及其对关系抽取的影响|同左|

最后再做“增强开/关 × 修正开/关”的 2×2 实验，说明互补性；不能用完整系统一个分数分别证明两项贡献，也不能在没有交互证据时宣称协同增益。

**以用户要求的严格尺度判断：目前两项研究问题可以区分，但第一项增量新意尚需直接近邻对照，第二项完整机制尚缺证据。现在写成“两项创新已充分成立”是不合适的。**

## 七、下一次投入应该只做什么

建议只批准一个有边界的中等规模验证阶段，不直接开展全套论文实验：

1. **固定一个有竞争力的初始抽取器。** 优先用用户原模型及真实预测；若无法提供，则重新实现公开神经基线，但标为新基线。保存 OOF、校准、审计预测。不要在本次已看过的审计集上反复选择模型后再称其独立验证集。
2. **先补动作可达性。** 在实际错误分布上对比单组件动作与有界局部重分割，报告合法预算下的可达恢复、不同分割错误的占比，以及候选/关系计算成本。
3. **只训练并验证评分器。** 固定候选与事务池，对比分类能量、简单剪枝和事务收益排序；包含 NONE、不修改、中性改写。用新的验证划分或嵌套交叉验证锁定规则，最终测试只在方案冻结后使用。
4. **门槛通过再实现完整事务。** 必须在 AAEC 和 CDCP 上都观察到非删除主动恢复的可信证据，并在完整预测端点关系任务中检查净收益；若只对一种语料有效，诚实收窄适用范围。
5. **第一创新同步做最小证伪对照。** 先用同一抽取骨干比较 QOS、QOS+筛选、显式关系条件局部增强。如果与最近邻差异被消除，不再靠换措辞保留创新，应重构研究问题。

建议停止/转向条件：

- 强模型下，候选已覆盖却动作在合理预算下仍不可达：先重构动作，不扩大生成预算。
- 有非删除好事务，但评分排名无法超过简单基线：优先修改评分训练，不堆搜索轮数。
- 只能稳定删除、不能增加正确组件或关系：降格为剪枝研究，不再主张完整联合恢复。
- 同评分器全局解码或顺序修正已经达到同样质量与成本：不把事务封装本身当作充分创新。
- 第一创新在 QOS/随机中心/等预算筛选后无独立增益：调整第一章和第三章贡献定位，不能拿第二创新成果补它的证明。

这些是可证伪的研究决策规则，不是保证结果符合预期。两项创新是否足够，最终取决于这两条独立证据链的质量，而不是创新标题的数量。
