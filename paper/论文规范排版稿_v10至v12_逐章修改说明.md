## 3. 全局统一后的关键用语

| 对象 | 统一表述 |
|---|---|
| 训练/推理组合 | T0I0、T1I0、T0I1、T1I1；四种配置 |
| 继承与新增推理 | I0 为完整继承链；R_DC 为追加修正；I1 为 I0 串接 R_DC |
| BR-J / SetLocal | 追加修正中的集合局部子程序，不泛指完整 I1 |
| 训练审核与推理评分 | 自动审核器 V；冻结对象评分器 S；避免混称“验证器” |
| F1 差值 | “百分点”，与 F1 百分制数值区别 |
| 置信区间 | “单项 95% CI”；与 Holm 家族校正后的显著性分别说明 |
| 显著性 | “Holm 校正后达到/未达到统计显著性”，不写笼统的“通过校正” |
| 求解结论 | 冻结候选宇宙内的代理目标最优证书；确定性破同分得到规范化输出 |
| 增强审核比例 | 明确不安全接受率的分母，不以“整体漂移率”泛化 |

全局终审重点防止三类含义混淆：整套配置改善与单个机制贡献；代理效用与实际严格 F1；作者提供的真实实验结果与本轮文档核查所能独立确认的内容。
