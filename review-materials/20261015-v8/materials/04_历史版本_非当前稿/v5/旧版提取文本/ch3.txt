第3章 基于可靠监督与一致性学习的论辩挖掘方法

[P236; PDF页33; Body Text]
利用语言模型对已标注文本进行局部改写，是扩充论辩挖掘训练数据的一种常用方式。然而，论辩组件与关系相互依赖，改写后部分原有标注可能已经失效，直接沿用全部原标注会把错误监督引入训练。针对上述问题，本章聚焦训练阶段增强监督的可靠性，提出可靠监督与一致性学习方法。具体地，通过关系影响域确定一处改写可能波及的组件与关系，通过语义审核筛选其中仍然可靠的部分，并仅在这些可靠的组件与关系上施加辅助监督和一致性约束，从而在扩充训练数据的同时避免引入错误监督。本章首先介绍总体框架与基础模型，然后依次说明可靠增强数据的构造方法与一致性学习的训练目标，最后通过对照实验分析方法的整体效果、一致性项的作用以及增强数据的审核质量与成本。

[P237; PDF页待定位; Heading 2]
3.1 引言

[P238; PDF页33; Normal]
论辩挖掘需要从文本中识别论辩组件并确定组件之间的关系，而在论辩文本中，组件的文字既决定其自身的类型，也是判断它与其他组件之间关系的依据。由于此类结构化标注的构建成本较高，对已标注文本进行局部改写以扩充训练样本，是缓解监督不足的一种自然思路。然而，局部改写即使基本保持句意，也可能改变支持关系的方向、削弱跨越改写边界的理由，或使原本无关的两个组件产生联系；若将原有标签全部照搬到改写文本上，新增样本就可能带来错误的监督。

[P239; PDF页33; Normal]
近年来，研究者开始借助语言模型的生成能力构造论辩挖掘的增强数据。例如，质量导向的合成方法QOS[6]将上下文与组件组织为槽位化输入，在改写后恢复组件跨度，并直接继承原有的组件类型与关系标注，为局部改写提供了实现基础。然而，这类方法默认改写保持了语义、原标注在改写文本上依然成立，对于组件与关系相互依赖的论辩结构，这一假设仍面临两个问题。一方面，改写影响的并不只是被改写的组件本身，与之相连的关系、跨越改写边界的关系以及原本没有关系的组件对，其状态都可能随之改变，若不界定改写的影响范围并逐项判断监督是否可靠，错误标签就会混入训练；另一方面，即使筛选出了可靠的监督，若仅将改写文本作为独立样本参与训练，也无法约束模型对原文与改写文本中相互对应的组件和关系给出一致的判断，增强数据所提供的对应信息未能得到充分利用。

[P240; PDF页34; Normal]
针对上述问题，本章提出可靠监督与一致性学习方法，旨在扩充训练数据的同时，只让改写后仍然可靠的组件与关系参与学习，并利用原文与改写文本之间的对应关系约束模型预测的一致性。具体而言，首先，确定一处改写可能影响的组件和关系，即关系影响域，并在字符坐标上将全部组件迁移到改写文本中；其次，分别审核组件与关系，凡是状态改变、无法判定或未经审核的，均不参与增强侧的监督；最后，在原文与改写文本之间，仅对可靠的组件与关系施加一致性约束，并结合原始标注进行辅助监督。

[P241; PDF页34; Normal]
为便于叙述，本章将同一篇文档的原文与其改写版本看作对同一内容的两种表述，称为两个“视图”，二者构成一组成对视图；同时，将可以单独决定是否参与监督的一项判断称为一个“因素”，它既可以是一个组件的类型，也可以是一组端点组件之间的关系状态。在此基础上，一致性学习要求模型对两个视图中相互对应的可靠因素给出一致的预测。由于可靠因素决定了哪些标签参与学习，而一致性项仅在这些因素上施加约束，在增强数据与掩码固定的条件下，即可单独衡量一致性项带来的增益。本章的主要符号见目录后的主要符号对照表。

[P242; PDF页10,34; Heading 2]
3.2 总体框架与基础模型

[P243; PDF页34; Normal]
本章方法的整体框架分为增强构造与参数学习两个阶段：构造阶段以训练文档及其标注为输入，输出改写后的全文、改写前后组件之间的对应关系φ以及可靠因素的掩码；学习阶段保留原文的完整生成监督，增强文本则只使用通过审核的因素，具体结构见3.4节图3.2。本章围绕关系影响域约束、可靠因素监督与一致性目标组织训练过程。抽取生成器采用类型条件LoRA的全局与结论双分支，并结合结论线索提示与句子辅助监督，这些模型配置沿用MCR-BR[56]的设置。增强生成器A、自动审核器V与抽取生成器G分别负责构造改写文本、审核监督和抽取论辩结构（见表3.8），三者通过组件对应关系与因素掩码相互衔接。

[P244; PDF页34; Normal]
因素掩码是随监督信号一同保存的0/1标记：取1表示该因素参与增强侧的监督与一致性约束，取0则表示不参与。掩码既不遮蔽输入文字，也不删除原始标注，组件掩码与关系掩码分别保存。

[P245; PDF页35; Normal]
抽取生成器采用Qwen3.5-9B[80]的文本部分，该模型共32层、隐藏维度为4096[80]；全局分支与结论专项分支两组LoRA均挂载在8个全注意力块的q/k/v/o投影上，取r=16、α=32、dropout=0.05，其余24个线性注意力块、前馈层和视觉编码器保持冻结[81]。对于投影矩阵W0，带门控的双分支LoRA输出定义为：

[P246; PDF页待定位; Normal]
 |  |  | h′t=W0ht+αrBgAght+gtαrBcAcht,  A⋅∈ℝr×din, B⋅∈ℝdout×r, | （3-1）

[P247; PDF页35; Normal]
其中，下标g、c分别表示全局分支与结论分支，h和h′分别为位置t的输入表示与输出表示。

[P248; PDF页待定位; Normal]
全局分支作用于所有位置，结论分支则由门控gt∈{0,1}控制。具体而言，模型对每个组件依次输出id（编号）、type（类型）和span（原文片段）三个字段，当某一组件的类型字段已输出为结论类（AAEC中为论点或主论点，CDCP中为政策或价值）时，门控在该组件的后续字段上开启，并在组件结束时关闭；其余位置以及关系部分均有gt=0。由于门控仅依据已生成的前缀决定，训练时也不会读取后续答案。

[P249; PDF页35; Normal]
当文本中出现therefore、thus、in conclusion、consequently、hence、to conclude这六类结论线索词时（不区分大小写，按词边界匹配），模型在输入嵌入前插入四个可训练的提示向量，否则不插入[63]，原文与增强文本分别判断是否触发。线索词仅用于触发提示，并不直接决定组件标签[46]。

[P250; PDF页35; Normal]
生成目标对回答部分的全部token（含结束符EOS）取平均，聊天模板与提示向量均不计入损失，计算方式如下：

[P251; PDF页待定位; Normal]
 |  |  | Lgenx,G=−1Tyt=1Tylogpθyt∣x,y<t. | （3-2）

[P252; PDF页35; Normal]
句子辅助任务沿用MCR-BR的设置：按句末标点切分句子后，对每个句子的末层表示进行均值池化，再经线性层和sigmoid函数得到该句含有结论的概率zi；若句子与结论类组件存在重叠，则zi=1，否则为0。句子损失与生成损失共同构成原文的基础监督目标，定义为：

[P253; PDF页待定位; Normal]
 |  |  | Lsent=−1Nsi=1Nszilogzi+1−zilog1−zi,  LIC=Lgen+λsentLsent, | （3-3）

[P254; PDF页待定位; Normal]
其中，λsent=0.5，句子头仅用于辅助表示学习。在上述基础监督之上，3.3节介绍增强文本的构造，3.4节介绍新增的可靠因素监督与一致性目标。

3.3 基于关系影响域的可靠增强数据构造

[P256; PDF页10,36; Heading 3]
3.3.1 改写范围与关系影响域

[P257; PDF页36; Normal]
本章构造增强文本时不改变组件类型与关系标注，仅替换部分已标注组件的文字，被替换的组件构成改写集合，且可以分布在不同段落中。相应地，下文所说的“内部”与“跨边界”按关系的端点是否全部位于改写集合中区分，与句子或段落的划分无关。

[P258; PDF页36; Normal]
为便于描述，本章将允许替换文字的组件片段称为“槽位”，将文字保持不变的其他组件称为“只读组件”；由于前面的改写可能改变文本长度，只读组件的字符位置也需随之更新。此外，下文的“正关系”指带有明确标签（如支持、攻击）的关系，与表示无关系的NONE相对。

[P259; PDF页36; Normal]
以AAEC训练文档essay001为例，如表3.1所示，T4、T5和T6均以支持关系指向T3，而T4与T7之间没有关系。若取改写集合A={T3,T4}，则T4→T3为内部正关系，T5→T3与T6→T3为跨边界正关系，T4→T7为跨边界NONE。该集合仅用于说明上述概念，按默认规则以T3为中心时，所有指向T3的源组件T4、T5、T6都会进入改写集合。

每篇训练文档选定一个改写中心，同一篇文档的所有改写样本均使用该中心。AAEC优先从论点和主论点中选取，CDCP优先从政策和价值中选取；为使选择结果确定且可复现，将固定种子17、语料名、文档ID、组件ID和center标记用竖线连接后计算SHA-256，并按其前16位的数值升序选取，若不存在优先类型的组件，则在全部合法组件中按同样顺序选取。

[P265; PDF页38; Normal]
在生成预算上，每篇文档最多尝试生成四次、最多接受两个改写样本，原始样本始终保留；若槽位相互重叠或输入超过上下文长度上限，则跳过该文档的增强。

[P266; PDF页待定位; Normal]
关系影响域建立在全部候选关系因素之上。记ΩC为所有合法端点组合构成的集合，其中每个关系因素ω=S,v由非空源组件集合S和目标组件v组成；AAEC中S=1，因此枚举所有合法的有向组件对即可。因素标签yω表示该端点组合的关系状态，没有标注关系的组合记为NONE。

[P267; PDF页待定位; Normal]

[P268; PDF页38; Normal]
相应地，CDCP的候选端点组合既包括全部金标关系的端点组合，也包括按源范围规则补充的、最多含三个源组件的组合，源组件超过三个的金标关系同样完整保留。

[P269; PDF页38; Normal]
关系影响域用于刻画一处改写可能波及的关系范围：只要某个因素的端点中有组件被改写，该因素的状态就可能随之改变。设Vω=S∪{v}为因素ω的全部端点，则改写集合A的完整关系影响域定义为至少有一个端点落在改写集合中的全部因素，即：

 |  |  | DA={ω∈ΩsemC:Vω∩A≠∅}, | （3-4）

[P271; PDF页待定位; Normal]
其中，ΩsemC=ΩC∖Usem，语义未知集合Usem见3.3.3节（AAEC中为空）；在二元情形下，该定义即为{u,v:u∈A∨v∈A,u,v∈ΩsemC}。全部端点都在A中的因素称为内部因素，只有部分端点在A中的因素称为跨边界因素。此外，改写还可能通过指代等上下文影响只读组件之间的关系，这部分由3.5.5节的人工抽查评估。

[P272; PDF页10,39; Heading 3]
3.3.2 改写生成与标注迁移

[P273; PDF页39; Normal]
增强生成器A使用不加载任务LoRA的Qwen3.5-9B，采样参数为temperature=0.7、top-p=0.9[82]，关闭thinking模式，每次最多输出2048个token，跨骨干实验也共用其生成的增强文本。生成器的输入包括训练文档全文、可改写的槽位及其类型、只读组件列表以及影响域标签，输出仅为从组件编号到替换文本的JSON映射，既不能新增组件，也不能修改类型或关系。

[P274; PDF页39; Normal]
替换槽位文字通常会改变文本长度：改写后，未改写组件在全文中的字符位置也会整体平移，因此需要先建立改写前后的组件对应，再检查原标签是否仍然成立。坐标迁移解决的是组件在新文本中的定位问题，而3.3.3节的语义审核解决的是原有监督能否沿用的问题。具体而言，程序按原始字符区间替换槽位文字，然后对整篇文档重新分词，并建立改写前后组件之间的对应关系：

[P275; PDF页待定位; Normal]
 |  |  | φ:C→C′,  (d,bc,ec,tc)↦(d′,bc′,ec′,tc), | （3-5）

[P276; PDF页39; Normal]
其中，d′表示改写后的全文，它是同一文档的一个新的文本版本。回填文字后，程序先更新全部组件的字符区间，使只读组件随前文长度的变化而平移，再重新生成分词与子词表示；因此，φ是组件之间的一一对应，而不是字符或token位置之间的对应，所有关系的端点都按φ迁移到新文本上。例如，被改写组件增加一个字符后，位于其后的只读组件在新文本中的起止位置都会后移一个字符，但其文字和标注保持不变。若出现槽位重叠、坐标无法对应或端点无法迁移，则丢弃该改写样本，只保留原始样本。

[P277; PDF页39; Normal]
在此基础上，3.3.3节介绍如何审核迁移后的标注，3.3.4节再通过真实文档的案例展示坐标迁移与审核的具体过程。

[P278; PDF页10,39; Heading 3]
3.3.3 语义审核与因素掩码

[P279; PDF页39; Normal]
迁移后的改写样本需要依次经过格式检查与语义审核。所有改写样本首先须通过格式检查，包括JSON格式、槽位编号、坐标对应和关系端点引用；之后，审核器V分别读取原文与改写文本，在看不到原标签的条件下输出组件类型或关系状态，再由程序与原标注进行比较。组件审核同时检查含义、论辩角色、指代、否定和情态，只要有组件含义改变、无法判定或输出不合法，就丢弃该改写样本。

[P280; PDF页40; Normal]
审核器V同样使用不加载抽取LoRA的Qwen3.5-9B，关闭thinking模式并采用贪心解码，每次最多输出1024个token，跨骨干实验共用9B模型生成的同一审核结果。

[P281; PDF页待定位; Normal]
组件全部通过审核后，再对关系进行审核。关系审核集合JA⊆DA包括全部受影响的正关系，以及从内部NONE和跨边界NONE中各随机抽取的至多4项，CDCP中被定义为语义未知的真子集不作为NONE负例。若无法审核完全部正关系，该样本不参与关系学习，但通过审核的组件仍可用于组件监督；未经审核的NONE则不参与监督。

[P282; PDF页40; Normal]
关系掩码的取值同时取决于关系自身及其端点组件的审核结果。只有当审核器认可原标注、改写后状态不变且端点对应有效时，关系掩码才取mRω=1，若原标签存在分歧、状态改变或无法判定，掩码取0；组件掩码mCc则单独保存。由于文字不变并不能保证论辩角色不变，关系所连接的只读组件同样需要在全文上下文中审核，关系掩码为1还要求其所有端点的组件掩码均为1。满足上述条件的因素称为“可靠因素”，审核质量见3.5.5节。

[P283; PDF页40; Normal]
对于掩码为0的因素，本章进一步区分两种情况：“待定”指审核过但无法确定原状态是否保持，“未审核”指没有对该因素进行审核，二者的增强侧掩码均为0，原关系标签保持不变；“语义未知”则属于另一种情况，见下文。

[P284; PDF页40; Normal]
在此基础上，默认策略保留通过审核的组件，既不会因为某一条关系未通过审核就丢弃全部组件，也不会把这条关系改标为NONE，增强侧的损失只使用掩码为1的标签。作为对照，完整筛选策略检查影响域内的全部因素，只要有一个因素改变或待定就丢弃整个样本，3.5节比较了两种策略在监督覆盖、训练效果和成本上的差异。

[P285; PDF页待定位; Normal]
多前提关系需要额外处理。严格评价要求预测关系与金标关系完全一致，例如金标为h={c1,c2},c3,Reason时，预测{c1},c3,Reason因源集合不同而不能匹配；但这并不意味着c1单独与c3没有关系，因为c1与c2共同构成理由，并不能由此推出c1单独既不支持也不反对c3。

[P286; PDF页待定位; Normal]
因此，本章为训练阶段的关系头定义语义未知集合Usem：对于一条已标注的多前提关系，若其源集合的某个非空真子集没有单独的正关系标注，就将该真子集与目标构成的因素列为语义未知。相应地，可审核的因素集合为Ωsem=Ω∖Usem，完整影响域与抽样均在该集合中定义。

[P287; PDF页待定位; Normal]
无论原文还是改写文本，关系头都不把Usem当作NONE负例，其监督掩码与一致性约束掩码均为0，而原文的完整生成目标仍保留原始的多前提关系。与此不同，第4章的评分器判断的是对象是否与标注完全匹配，因此可以把这类真子集作为“不匹配”的负例，但这并不表示其在语义上没有关系。

[P288; PDF页待定位; Normal]
记通过审核且端点组件也都通过审核的关系集合为RA，则上述各集合满足如下包含关系：

[P289; PDF页待定位; Normal]
 |  |  | RA⊆JA⊆DA⊆Ωsem,  Ωsem=Ω∖Usem, | （3-6）

[P290; PDF页待定位; Normal]
其中，完整影响域DA是定义范围，JA是实际审核的范围，只有通过审核的RA才进入增强侧的关系损失。默认策略下JA通常小于DA，完整筛选策略则要求JA=DA，语义未知集合Usem始终不在两者之中，图3.1中的两条路径即对应这一层级关系。

3.4.1 辅助预测头与一致性约束

[P306; PDF页46; Normal]
为在因素粒度上施加监督与一致性约束，本章在生成器之上设置组件类型头与关系状态头两个辅助分类器，二者读取生成器对输入文本的隐藏表示，并用金标跨度定位待预测的组件。抽取生成器的输入仅包含任务指令与文本本身，金标的槽位、类型和关系只用于构造训练样本与监督信号，并不作为生成器的输入。

[P307; PDF页待定位; Normal]
令hix为第i个输入子词的隐藏状态，Bxc为组件c的字符跨度所覆盖的子词集合，hendx为输入结束、回答开始之前位置的隐藏状态，则组件表示与类型分布定义为：

[P308; PDF页待定位; Normal]
 |  |  | ucx=MeanPooli∈Bxchix,  pCxc=softmaxfCucx;hendx, | （3-7）

[P309; PDF页46; Normal]
其中，MeanPool表示对组件覆盖的子词表示取均值，方括号表示向量拼接。由于生成器为因果模型，靠前的token只能看到左侧的上下文，拼接hendx可以为组件表示补充全文信息；组件头的输入不包含金标类型。

[P310; PDF页46; Normal]
与组件头输出类型分布不同，关系头输出一组端点之间的关系状态分布，并显式区分源组件与目标组件：

[P311; PDF页待定位; Normal]
 |  |  | pRxS,v=softmaxfRPool{ucx:c∈S};uvx;hendx;ηS,v, | （3-8）

[P312; PDF页待定位; Normal]
其中，fC、fR为两层感知机，Pool对各源组件的表示取均值；η为位置特征，由源组件数与六个位置统计量组成，后者包括源组件起点的最小值与均值、终点的最大值与均值以及目标的起止位置。位置先由字符区间换算为评价token坐标，再除以文档的token数进行归一化，且不包含待预测的关系标签。二元关系只有一个源组件，多前提关系则以完整的源集合与目标为预测对象，状态中均包含NONE；两个辅助头在验证和测试时均会移除。

[P313; PDF页46; Normal]
组件一致性约束的范围包括被改写的组件，以及通过正关系与之相连的只读组件，定义为：

[P314; PDF页待定位; Normal]
 |  |  | A+=A∪⋃ω∈DA, yω≠NONEVω, | （3-9）

[P315; PDF页47; Normal]
其中，并集只对影响域中的正关系因素取端点，NONE因素仅参与关系一致性约束，因而不会把距离较远的组件也纳入组件一致性约束。对于通过组件审核的改写文本x′，下式中的A+还需与{c:mCc=1}取交集，组件一致性损失定义为：

[P316; PDF页待定位; Normal]
 |  |  | LCalignx,x′=1A+c∈A+​JSpCxc,pCx′φc, | （3-10）

[P317; PDF页47; Normal]
其中，JS为式（2-7）定义的Jensen–Shannon散度，两个视图均保留梯度，共同参与参数更新。类似地，将通过审核的关系因素集合{ω∈JA:mRω=1}划分为正关系组D+与NONE组D0，记非空的组为B={b∈{+,0}:Db>0}，关系一致性损失先在组内平均、再在组间平均：

[P318; PDF页待定位; Normal]
 |  |  | LRalignx,x′=1Bb∈B​1Dbω∈Db​JSpRxω,pRx′φω, | （3-11）

[P319; PDF页47; Normal]
其中，分组平均可以避免数量较多的NONE因素主导关系一致性损失。没有可靠关系时，关系一致性项为0，但原文全部关系的生成监督不受影响；A+为空时，组件一致性项同样为0。

[P320; PDF页47; Normal]
仅约束两个视图的预测分布相互接近，并不能保证预测与金标一致：当两个视图产生相同的错误时，JS散度依然很小。因此，训练目标还需结合因素级监督，分别约束预测的一致性与正确性。对于视图x，记MC和MR分别为受监督的组件集合与关系因素集合，MR+和MR0分别为其中的正关系与NONE，BM={b∈{+,0}:MRb>0}，则辅助监督损失定义为：

[P321; PDF页待定位; Normal]
 |  |  | Sx;MC,MR=1MCc∈MC​CEpCxc,tc+1BMb∈BM​1MRbω∈MRb​CEpRxω,yω, | （3-12）

[P322; PDF页待定位; Normal]
其中，CE为交叉熵，tc为组件的原始类型；MC=∅时组件项为0，BM=∅时关系项为0，两项等权相加。原文取Sx,G=Sx;C,ΩsemC，即使用全部组件与可审核的关系因素；改写文本取Smx′,φG=Sx′;{φc:mCc=1},{φω:ω∈JA,mRω=1}，即仅使用掩码为1的组件与关系。由此，一致性约束与原始标注的监督相互配合，使模型在两个视图上的预测既保持一致又接近正确标签。

3.4.2 损失归一化与参数更新

[P324; PDF页48; Normal]
为避免改写样本数量不同的源文档在训练中获得不均衡的权重，本章按源文档对各项损失进行归一化。设源文档d有md个被接受的改写样本，原文承担完整的论辩图生成监督与句子监督；改写文本则只作为输入，由于其中可能含有未审核的关系，不将其完整论辩图作为生成目标。辅助监督损失定义为：

[P325; PDF页待定位; Normal]
 |  |  | Lheads,dsup=Sxd,Gd+j=1mdSmjx′dj,φjGd1+md. | （3-13）

[P326; PDF页48; Normal]
一致性项先在每个非空因素组内平均，再在同一源文档的各改写样本之间平均，总损失定义为：

[P327; PDF页待定位; Normal]
 |  |  | Ld=LICxd,Gd+λsupLheads,dsup+λCLC,dalign+λRLR,dalign, | （3-14）

[P328; PDF页待定位; Normal]
其中，默认取λsup=1、λC=λR=0.5。没有改写样本时只保留原文的各项损失；有改写样本但没有可靠关系时，关系一致性项为0，组件学习照常进行。由于被接受样本中的改写组件都已通过审核，mC均为1，计入md的样本不会出现空的组件项。此外，每个批次内按源文档取平均，以避免改写样本较多的文档获得过高权重。

[P329; PDF页待定位; Normal]
以3.3.4节的例子说明上述归一化过程：一个被接受的改写样本使md=1，原文与改写文本的辅助监督各占1/2；A+={T3,T4,T5,T6}，组件一致性项对这4个组件取平均；关系一致性项中有3项正关系和8项NONE，分组平均后，在λR=0.5时每项正关系与每项NONE的最终权重分别为1/12和1/32。

[P330; PDF页待定位; Normal]
按1+md取平均使每篇源文档的辅助监督总权重固定，原文在其中的占比为1/1+md，而原文的生成损失LIC保持不变。由于完整筛选与因素掩码接受的样本数量通常不同，二者的比较也包含原文占比的差异；一致性学习的消融则固定了样本与掩码，不受此影响。

[P331; PDF页48; Normal]
在参数更新上，生成损失与句子损失更新原有模块，组件头、关系头与一致性项通过共享的输入表示更新全局LoRA，结论分支只随相应的生成路径更新；基础权重保持冻结，辅助头在评价时移除。第4章的推理评分器另行训练，不使用这些辅助头的输出概率。

[P332; PDF页11,49; Heading 3]
3.4.3 算法流程与性质分析

[P333; PDF页49; Normal]
算法3-1概括了本章方法的主要步骤，包括增强构造与参数学习两个阶段：先在固定预算内生成并筛选改写样本，再按源文档归一化进行训练。两个阶段都只使用训练集，验证集仅用于参数选择和早停。

[T05; PDF页49; 表格]
算法3-1 可靠监督与一致性学习
输入：训练文档及其标注Dtrain，增强生成器A、自动审核器V；
　　　尝试上限Btry、接受上限Baccept、更新上限U，mode∈{FactorMask, FullFilter}。
输出：训练后的生成器θ、增强样本及组件对应关系。
01 检查数据划分、去重分组与标注坐标，依次处理源文档，保留原文及完整金标图。
02 按3.3.1节选取改写中心及全部源组件；无法处理则跳过该文档。
03 排除语义未知因素，构造Ωsem、改写集合A及完整影响域DA。
04 在Btry次尝试和Baccept个接受样本的上限内，重复步骤05—08。
05 生成并回填替换文本，重新分词，建立全部组件的双射φ。
06 格式、槽位、坐标或端点检查失败，或组件含义、论辩角色改变或无法判定时，拒绝样本。
07 对非空DA，FullFilter审核全部因素，无法全部审核或任一项未通过则拒绝；FactorMask审核全部受影响正关系及抽样的内部、跨边界NONE，得到mR。
08 保存改写文本、迁移标注、φ及因素掩码；无接受样本时仅使用原文。
09 构造完成后按源文档采样训练批次，重复步骤10—12，直至达到U或满足早停条件。
10 计算原文生成损失、句子监督损失，以及原文可审核因素和增强文本可靠因素的辅助监督损失。
11 按φ计算可靠因素的一致性损失，无可靠因素时该项为0；各项损失按改写样本和源文档两级归一化。
12 冻结基础模型权重，反向传播并更新LoRA与辅助头参数。
13 返回生成器及增强数据，评价和测试时移除辅助头。

[P334; PDF页待定位; Normal]
性质一（标注迁移保持结构）。若改写槽位互不重叠、φ是组件之间的双射，且组件类型与每条完整关系都按φ迁移，则G与φG具有相同的组件数、组件类型以及带方向和标签的关系结构。证明：双射保证每个原组件恰好对应一个新组件，而关系的全部端点逐一映射，因此关系既不会增加也不会丢失，利用逆映射即可恢复原图。该性质仅保证标注结构不变，改写后的文本是否仍然支持这些标签，需由3.3.3节的语义审核判断。

[P335; PDF页待定位; Normal]
性质二（单因素预测稳定的充分条件）。对某一因素，设原视图中的正确类别为y，预测分布p的间隔为γ=py−maxk≠ypk>0。若增强视图的分布q满足∥p−q∥∞<γ/2，则argmaxq=y。证明：对任意k≠y，都有qy−qk>py−pk−γ≥0。该性质表明，只要两个视图的预测分布足够接近，增强视图就能保持原视图的正确预测，这正是一致性约束的出发点。

[P336; PDF页50; Normal]
综上，性质一保证了标注迁移不破坏论辩结构，性质二说明了一致性约束为何有助于预测稳定，3.5节将通过实验检验上述设计在完整论辩图抽取上的效果。

3.5.2 对照方法

[P346; PDF页51; Normal]
为全面评估本章方法的有效性，并区分数据构造方式与学习目标各自的作用，本节按表3.5设置九组训练对照，主要包括以下四类。

[P347; PDF页52; Normal]
（1）基线配置。以MCR-BR训练配置（记为T0）为基线，推理采用MCR-BR的推理流程（重排序、合法化与BR-O，记为I0），该组合记为T0I0；在其基础上仅在原文上增加辅助预测头监督、不使用增强数据的配置记为Heads，用于区分辅助头本身带来的影响。

[P348; PDF页52; Normal]
（2）增强构造对照。普通改写增强（Plain）与槽位化增强（QOS）按各自的构造规则产生增强样本，二者仅与本章方法匹配接受样本的规模，用于考察可靠监督构造本身的作用。

[P349; PDF页52; Normal]
（3）学习目标对照。去掉一致性项（NoPair）只使用可靠因素监督而不施加一致性约束，仅组件一致性（CompPair）只在组件上施加一致性约束，本章完整训练配置（记为T1，在I0推理下记为T1I0）则同时约束组件与关系；三者使用完全相同的改写样本、因素掩码与辅助头，仅在学习目标上不同，因而其差值能够直接反映一致性目标的作用。

[P350; PDF页52; Normal]
（4）筛选策略与改写中心对照。完整影响域筛选（FullFilter）在任一因素未通过审核时丢弃整个改写样本，随机中心（RandomCenter）则随机选择改写中心，二者作为可独立选择的策略与默认设置进行比较。

[P351; PDF页52; Normal]
为保证比较的公平性，九组对照使用相同的骨干、源文档访问次数和更新步数，推理均采用I0，各增强组的接受样本规模相同（AAEC 500个，CDCP 900个），成本统计同时计入生成失败、被拒样本与审核的开销。在此基础上，比较学习目标时固定增强文本、因素掩码和辅助头，比较数据构造方式时则保持接受样本规模与训练预算相同；推理侧修正策略的对照属于第4章，见4.6.1节。

3.5.5 增强数据的人工审核

[P371; PDF页59; Normal]
为独立评估增强监督的质量，本节在自动审核器V之外另设人工分层审核，由两名审核员A、B与一名裁决人C完成；由于增强器与自动审核器使用同一基础模型，二者可能具有相关偏差，人工审核因而作为独立参照。A与B分别将每个因素判为状态保持（stable）、状态改变（changed）、无法判定（undecided）或不认同原标注（original_disagreement），C先独立判断，再给出最终结论；三人先以60项培训材料统一标准，培训阶段的一致性κ为0.86。在抽样方面，组件审核同时覆盖被接受与被拒绝的样本，关系审核则从训练增强池中分四层抽样，每层最多300项，不足300项时全部审核，抽样概率为πh=nh/Nh。

3.6 本章小结

[P389; PDF页65; Normal]
针对训练文本局部改写后部分标注可能失效、直接沿用原标签会引入错误监督的问题，本章提出了可靠监督与一致性学习方法。该方法首先通过关系影响域确定改写可能影响的组件与关系，并借助组件对应映射将原标注无损地迁移到改写文本上；在此基础上，通过语义审核与因素掩码确定增强侧监督的范围，使只有可靠的组件与关系参与学习；进而在可靠因素上施加一致性约束，并按源文档归一化控制改写样本数量带来的权重差异。在AAEC和CDCP上的实验结果表明，该方法使严格关系F1相对同骨干的MCR-BR基线分别提高2.56%和3.30%；在固定增强样本与因素掩码的条件下，一致性目标本身带来1.39%和2.57%的提升，且均通过多重比较校正。此外，人工分层审核显示被接受因素的加权不安全率低于1%，跨骨干实验也表明该训练方法在两种补充骨干上同样带来显著提升。

[P390; PDF页66; Body Text]
本章通过筛选可靠的增强监督并施加一致性约束，改善了模型在训练阶段学到的组件与关系预测，使因端点组件缺失或错误而无法命中的金标关系在AAEC上由637条减少到546条、在CDCP上由294条减少到260条（见4.6.5节表4.19）；然而，这部分关系仍分别占金标关系的约22.5%和34.4%，而组件一旦出错，以其为端点的关系也随之失效，单靠改进训练信号难以消除这类错误。因此，下一章将以本章所得模型为起点转向推理阶段，研究在不改动原文的前提下如何修改预测组件并同步重建受影响的关系，以获得满足任务约束的论辩结构。
