# 写作逻辑与文体规范：从全文主线到一句话

版本：2026-10-13 v2。用于依据现有成稿改善学术表达、段落节奏、信息密度和证据边界。它回答的不只是“哪些词可以删”，还包括“这条信息为何出现在这里、怎样接上前文、能支持多强的判断”。

按本次任务读取相应尺度。全文润色关注主线与章节，局部润色关注句段及必要上下文；下面的判断不要求每次输出五张检查表。分章节职责见 [各章节规范](chapter-guide.md)，更多句子示例见 [自然表达](natural-prose.md)。

## 1. 样本给出的依据与编辑取舍

代号与源文件指纹见 [来源说明](source-basis.md)。页码为 PDF 物理页。以下是具体写法观察及据此提出的编辑建议，不是对样本研究结论的认证。

| 样本位置 | 实际观察 | 提炼的写作规则 | 不照搬的部分 |
| --- | --- | --- | --- |
| C p36，§3.4.1 | 先交代批内负样本不足，再引入近期批次队列，随后说明旧嵌入限制队列长度 | 方法段按“障碍—选择—操作—必要限制”推进；每句引入新信息 | 不把全部公式释义挤进一个长句，也不删队列长度的设计原因 |
| T p39，§3.3.2—3.3.3 | 频次统计、时间加权、归一化和输出融合按操作依赖展开 | 用上一操作的输出引出下一操作，少靠抽象过渡词 | “有效捕捉、重要信息”等重复评价不必在每一步之后保留 |

本轮对 S p47、F p57 的段落与表格布局进行了页面核对。没有计算全语料平均句长、词频或“最佳信息密度”，因此不设这类数值标准。段落拆并和用词选择属于结合样本的编辑判断，不声称是五篇一致采用的固定规则。

## 2. 总体逻辑：让问题、方法和结果相互对应

先确定全文究竟要解释哪件事：在什么任务和条件下，现有做法遇到什么具体困难，本文改了哪里，现有结果回答了多少。可以用以下关系检查主线，但不必把它画进论文：

> 研究对象与条件 → 具体困难 → 研究问题 → 设计选择 → 对应证据 → 有范围的回答

箭头表示读者理解上的依赖，不表示每篇必须设置六个章节。若方法基于理论推导、系统设计或案例研究，证据形式随实际工作变化。

### 三处对照

1. **问题与方法对照**：绪论说要解决的困难，在方法章能找到实际处理步骤；方法中的关键设计也能找到动机。不要绪论强调效率，正文却只给效果结果而没有说明研究范围变化。
2. **方法与证据对照**：声称改善哪一方面，就由相应评价支撑；不能用流程能运行代替效果有效，用参数少代替运行快，用预测准确代替解释可信。
3. **结果与总结对照**：结论回收已展示的结果，保留重要例外，不在总结突然扩大任务、数据或适用人群。

这些是表达对应检查，不自动要求补实验。材料没有给出某个连接时，指出具体缺口，不为让故事完整而编出连接。

### 多项工作的关系怎样写

- **并列**：同一问题的两个侧面，分别说明分工，不强造先后依赖。
- **场景扩展**：交代变化的是输入、资源或任务条件，如 C 的静态到时序、S 的不同模型资源场景。
- **流程衔接**：明确前一阶段输出由后一阶段如何使用；只有真实存在接口时才这样写。
- **目标递进**：由一种能力拓展到另一种能力，如 T 的预测到推理过程；不自动意味着继承前一模型。

同一术语在各章保持同义。摘要、绪论、方法与总结可以重复核心名词，但承担不同任务：概括、立题、展开、回答。压缩无新增信息的完整段落回放，不把保持主线所需的重复也删掉。

## 3. 写作逻辑：先确定这节要回答的问题，再选材料顺序

一节不是“若干技术名词的集合”，而是对一个可说清问题的展开。拟定标题后，先用普通技术语言说出这节读完应明白什么，再安排定义、例子、步骤、公式或结果。

| 本节任务 | 合适的展开方式 | 常见断点 |
| --- | --- | --- |
| 解释动机 | 已有做法 → 具体困难或例子 → 本文选择 | 从宏大意义直接跳到新模块，没有解释它解决哪一步 |
| 说明方法 | 所需对象/输入 → 关键操作 → 输出与用途 → 相关条件 | 尚未定义对象就堆公式，或者只讲优点不讲操作 |
| 比较方案 | 明确比较维度 → 代表做法 → 相关差异 → 本文取舍 | 文献逐篇罗列，缺少共同的比较问题 |
| 解释结果 | 比较问题 → 主要观察 → 关键证据/例外 → 有依据的解释 | 先写结论口号，再挑数字装饰它 |
| 总结工作 | 本章或全文的问题 → 已完成的回答 → 仍未覆盖的部分 | 把章节目录改写成“首先介绍、然后阐述” |

表中的顺序是可选论述路径，不是每节都必须逐项填满。读者已经知道的定义可以回指；复杂新对象需要更多解释，不能为紧凑而省掉。

若只是局部语言润色，优先调整本节内部顺序和承接。需要搬动整章、改变贡献组织或新增主张时，先作为建议提出，不将“改善逻辑”当成扩大修改范围的授权。

## 4. 句段逻辑与段落节奏

### 段内：后一条信息为什么接在前一条后面

先判断相邻句是定义与展开、条件与操作、观察与解释、并列比较，还是转折。理清关系以后再选连接词，不先给每句补“此外、进一步、因此”。

- **定义与展开**：先给对象的最低必要说明，再讲它的细节，避免定义中又嵌入三个未解释术语。
- **操作链**：前句输出成为后句输入。例如“得到候选得分后，按得分排序”。
- **观察与解释**：先说看到的差异，再说可能原因；不能把解释当作结果表里的直接观察。
- **转折与取舍**：明确转的是哪个维度，如效果提高而耗时增加，不用笼统的“然而仍存在不足”。
- **指代承接**：“该结果、这种方法、上述问题”应能唯一指回；存在多个对象时重复准确名词比换代词更清楚。

### 段间：沿同一个问题向前，不反复重新起头

前段交代批内负样本少，后段就可以介绍怎样扩大负样本，而不必再次介绍整个对比学习领域。前段报告主结果，后段若转向模块作用，应说明比较问题变了，不仅补一句“进一步开展分析”。

新段最好利用已有信息承接，再引入新信息；这是一种可读性策略，不要求每段首句都回顾上段。段尾只有在确需归纳或导向下一步时才写总结，不能每段都用“提供有力支撑”收尾。

### 何时拆段，何时合段

适合拆段：核心问题改变；从现象转到较长的原因分析；从算法定义转到训练设置；在同一长段切换多个比较对象。S p47把几种消融放在一个长段，后续改写可以按问题分开，保留指标之间的联系。

适合合段：连续短段都在解释同一个操作，各段只有提示语和一句同义概括；或把紧密相连的条件和结果拆得太碎。合并后仍须看得出对象与逻辑关系。

节奏来自信息难度与任务变化：关键发现可用短句，方法条件及比较可用较长句，复杂推导允许展开。不要为了长短交替而制造碎句，也不要把段落统一成三句或五句。

### 句内：先找到主干，再处理修饰

检查“谁—做什么—作用于什么”，把真正的条件贴近所限定的动作。一个长句同时承担背景、设计、实现和效果判断时，可按功能拆开；单纯字数长但逻辑清楚的句子不必硬拆。

例如“采用模块 A，提高稳定性并确保泛化”的后半句可能是目的，也可能被读成已证实效果。若原意只是设计目的，可写“模块 A 用于……；其效果见……”，只有原文已有对应结果位置时才加回指，不能为句子完整而编一个实验。

## 5. 学术表达与用词：准确而平实

### 按动作选择词，而不是按正式程度堆词

| 想表达的内容 | 可以使用的说法 | 需要检查的误用 |
| --- | --- | --- |
| 本文新增的方案或定义 | 提出、设计、定义 | 已有算法仅被使用时，不写成“本文提出” |
| 数据、集合或结构的形成 | 构建、生成、筛选、组织 | “构建”之后需有具体对象，不只接抽象能力 |
| 已有技术的使用 | 采用、使用、引入 | 不把“引入已有组件”自动包装成新的理论贡献 |
| 过程与运算 | 编码、计算、排序、拼接、聚合、更新 | “实现有效协同”不能替代这些实际步骤 |
| 直接结果 | 高于、低于、下降、保持、结果显示 | 结果本来确定时不反复“可能在一定程度上” |
| 原因解释或线索 | 可能与……有关、提示、与……一致 | 这些措辞仍需要相关依据，不能充当随意猜测的许可证 |
| 有明确前提的严格推导 | 证明、推出、满足 | 单表排名或单个案例不足以支持普遍保证 |

这不是同义词替换表。具体句子是否合适由动作、证据和上下文决定，“显示”也可能接过强结论，“表明”也可以仅描述一个局部事实。

### 术语稳定，解释具体

同一个技术对象保持同一名称，不为了避免重复把“候选集合”换成“可行空间、关系池、搜索域”而引入潜在不同含义。首次解释必要含义，之后使用稳定简称；不同概念也不能为省字合并。

专业术语可以保留，连串抽象修饰要拆开。例如“结构一致性”若是正式约束就保留，并说清具体检查什么；“多维协同、高质量、全面提升”若没有对应对象或标准，优先改成具体动作或比较。

主体用词随对象：“本文”提出问题和方案，“模型/模块”执行计算，“实验”比较设置，“结果”支持判断。一般无需赋予算法“认为、意识到、努力”等人的心理，也不必把每句话都改成无人称被动句。

### 连接词承担明确关系

“因此”连接有根据的推导，不代替缺失前提；“随后”表示步骤，不自动表示因果；“相比”需要清楚对象与维度；“进一步”需要确实新增分析层次。内容本身衔接清楚时可以不加连接词。

“显著、有效、鲁棒、稳定、可靠、全面”不列入禁词，但检查其含义：统计显著需要实际检验，稳定性要有对应变化范围或重复证据，全面要有明确比较集合。没有对应证据时写具体观察，不用更弱的空词掩盖问题。

## 6. 信息密度：保留有用信息，减少读者的额外负担

信息密度不是单位字数中的术语数量，也不是越短越好。一个句子是否值得保留，看它是否新增读者需要的对象、条件、操作、证据、解释或限制；背景、过渡和重复也可以有用，前提是帮助理解。

可以这样处理：

1. **删空泛评价**：去掉“具有重要意义、提供有力支撑”等未增加信息的尾句；若具体作用尚未说清，补的是原稿已有作用，不是新的承诺。
2. **合并近距离重复**：章前概述和引言重复同一背景时分配职责，保留一次详细解释。T p51属于可压缩参照，不把原稿篇幅当标准。
3. **展开压缩过度的术语串**：把若干名词还原成操作，即使字数增加，也可能降低理解成本。
4. **让图表与正文分工**：表中保留全量数值，正文挑关键比较和必要例外；不能为了“高密度”把表中每格都塞进长句。
5. **保留理解支点**：关键定义、反例、接口条件和必要的小例子不能只因不含新结果而删除。

判断不靠压缩百分比。一个概念初次引入需要展开，后续复用可以简短；摘要要自足，不能以正文已说明为由删掉决定性条件。

## 7. 证据边界：断言直接，限定准确

| 信息状态 | 表达要点 | 不应改成 |
| --- | --- | --- |
| 设计目的 | “用于/旨在处理……”并说明具体操作 | 未有结果就写“已经有效解决……” |
| 表中直接观察 | 对象、指标、比较方向清楚，保留例外 | 从若干设置更优变成“普遍优于” |
| 原因尚未单独验证 | 说明依据，在解释处保留“可能”等限定 | 用消融差异直接宣布确定因果机制 |
| 尚未做统计检验 | 明确检验未做，必要时只陈述数值 | “检验未显著”或“统计显著” |
| 已检验但未显著 | 如实说明差异未达统计显著性 | “没有任何效果”或“已证明有效” |
| 合成、构造或估算结果 | 在相关任务范围、结果及自足摘要中保留性质 | 真实语料/模型上的已完成实验 |
| 尚未执行的工作 | “拟、计划、后续将”与已完成结果分开 | 用过去式或完成式表述为当前成果 |

共同条件可在小节开头交代一次，局部例外和推测放在相应句子。摘要、独立图注和结论可能脱离上下文阅读，必要范围不能一并删掉。表文冲突或版本不明时标出具体疑点，不靠选择更漂亮的数字完成润色。

## 8. 四个样本化示范

以下文字为本规范新写的示范性转述或构造，不是原论文原句，也不是对原论文做的正式修订。不能移入其他论文当成其研究事实。

### A. 学术表达：把抽象目的落实为操作（参照 C p36）

较空泛的构造句：为实现跨批次信息资源的充分利用，建立具有动态扩展能力的负样本增强机制。

根据该页已有步骤转述：为增加负样本，模型将近期批次的实体嵌入存入队列，供当前批次使用。队列只保留较近的批次，以减少旧嵌入与当前表示的差异。

取舍：补足对象、动作和必要限制，不增加性能结论；正式方法仍需保留该页采样条件和公式，示范不替代它们。

### B. 段落节奏：先读出动作之间的依赖（参照 T p39）

较挤的构造句：本文通过历史统计机制完成频次表征，并在时间窗口约束下实施差异化加权，进一步利用归一化机制实现候选实体分布构建，以支撑后续模型协同推理。

根据操作链转述：模型先统计候选实体在历史事实中出现的次数，再对时间窗口内的近期记录赋予更高权重。加权频次经归一化得到候选实体分布，随后与另一模块的预测分布融合。

取舍：在频次加工与分布融合之间形成停顿，后一条信息接住前一条输出。公式中的时间可见性、权重和融合系数仍需在正式段落保留，不以这两句话取代完整定义。

### C. 信息密度：一句关键比较胜过多次总体评价（参照 F p57表5.8）

较空泛的构造句：两种策略在模型效果改善方面具有积极意义，但协同收益并不总是呈现简单叠加的趋势，这也说明策略组合具有一定复杂性。

按表中对照转述：在emotion上，两种策略同时使用时的准确率为75.23%，低于仅使用信息增强时的75.58%。这一设置下，组合并未取得最优结果。

取舍：给出对象、数值与有限结论，不解释未验证的“为什么”。该页其他数值转述冲突不随此例一并认定或更正。

### D. 证据边界：局部比较和推测各在其位（参照 S p46—47）

结果转述：去掉风格奖励后，总ACC由98.69降至97.19，但总BLEU由33.50升至33.67，总PPL由66.17降至64.91。不同评价维度呈现出取舍。

原因转述：对于文言文PPL偏高的现象，作者结合生成用词提出了一种可能解释：模型使用了意义接近、但在目标风格中较少见的词。

取舍：两段分别对应不同问题，不把它们强接为一条因果链；表中的结果可直接写，原因保留推测身份。不能把自动指标变化扩写为人工评价也改善。

## 9. 实际润色时的处理顺序

在用户授权范围内，先检查信息对应与缺失承接，再调整段落组织和节奏，最后改句子与用词；完成后对照数值、术语、引用、条件与主张强度。若只改一句，不因此索取或审计全篇。

四个验收问题：同行是否更容易理解？每段是否有推进？重要信息是否完整且少重复？判断强度是否与现有材料相称？这四项同时成立，比单纯减少字数或减少某个词更重要。
